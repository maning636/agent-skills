# 商业长文调研来源指南

刘润风格商业长文创作前必须确认的信息来源清单。与原技术书 skill 的核心差异：从"技术准确性"为主改为"商业洞察"为主。

---

## 商业信息来源

### 一、公司财报与公告

| 信息类型 | 来源 | 优先级 |
|---------|------|--------|
| 中国上市公司财报 | 巨潮资讯网（cninfo.com.cn） | P0 |
| 上交所/深交所披露 | 上交所/深交所官网 | P0 |
| 美股上市公司财报 | SEC EDGAR（sec.gov/edgar） | P0 |
| 港股上市公司财报 | 港交所披露易（hkex.com.hk） | P0 |
| 数据库聚合 | Wind、Bloomberg、Choice | P1 |
| 季度业绩说明会 | 公司投资者关系页面 | P1 |

**使用规则**：
- 必须标注"截至XXXX年Q3"或具体日期
- 不在长文中编造任何数据
- 同比/环比必须标明对比基准

### 二、行业研究

| 信息类型 | 来源 | 优先级 |
|---------|------|--------|
| 卖方研报 | 中信证券、华泰证券、中金、海通 | P0 |
| 独立研究 | 艾瑞咨询、易观分析、赛迪顾问 | P0 |
| 全球研究 | Gartner、Forrester、IDC、CB Insights | P0 |
| 咨询公司 | 麦肯锡、波士顿咨询、贝恩、罗兰贝格 | P1 |
| 学术研究 | 长江商学院案例中心、中欧案例库 | P1 |
| 行业自媒体 | 36氪深度、晚点 LatePost | P1 |

**使用规则**：
- 引用研究数据时必须标注研究机构
- 优先使用 P0 级别来源
- 跨机构数据冲突时优先使用更新日期更近者

### 三、财经媒体

| 信息类型 | 来源 | 优先级 |
|---------|------|--------|
| 国内深度 | 财新、华尔街见闻、第一财经 | P0 |
| 国际深度 | FT、Bloomberg、WSJ、Reuters | P0 |
| 国内综合 | 21世纪经济报道、经济观察报 | P1 |
| 商业故事 | 虎嗅、钛媒体、亿邦动力 | P1 |
| 投资视角 | 投中网、PEdaily、清科 | P2 |

**使用规则**：
- 重大数据至少需要 2 个独立媒体来源验证

### 四、企业家访谈与公开演讲

| 信息类型 | 来源 | 优先级 |
|---------|------|--------|

| 公开演讲实录 | 公司年会、行业大会、毕业典礼 | P2 |

**使用规则**：
- 直接引用时必须标注来源、场合、时间
- 转述时标注「据XXX在某场合分享」
- 不臆造企业家语录

### 五、社交平台与自媒体

## 案例素材来源

### 一、企业家故事

**来源类型**：
- **传记**：《埃隆·马斯克传》（沃尔特·艾萨克森）、《稻盛和夫自传》、《贝佐斯传》（布拉德·斯通）、《任正非传》
- **公开访谈**：得到 App、混沌大学、湖畔大学公开课
- **演讲实录**：股东大会、年会、毕业典礼、行业大会
- **媒体报道**：财新、晚点 LatePost 的企业家专访

**使用规则**：
- 故事必须有时间、地点、人物、决策 4 要素
- 关键决策点必须有 2 个独立来源验证
- 标注信息时效（"2021年3月"等）

### 二、企业参访纪要

**来源类型**：
- **刘润访学团**：得到 App「刘润·进化岛」、公众号「刘润」参访系列
- **第三方参访**：混沌大学、湖畔大学、各商学院参访
- **公开报道**：财新、晚点、虎嗅的深度企业报道

**使用规则**：
- 优先使用"亲历者视角"（刘润本人参访过的企业）
- 第三方参访的视角与判断要明确标注非刘润观点
- 不杜撰参访细节

### 三、深度商业报道

| 媒体 | 特色 | 适合引用场景 |
|------|------|--------------|
| 36氪深度 | 创业公司、科技趋势 | 早期公司案例、模式创新 |
| 虎嗅 | 商业故事、战略复盘 | 大公司战略转型 |
| 钛媒体 | TMT、产业互联网 | 行业格局分析 |
| 晚点 LatePost | 头部公司深度报道 | 大公司决策、人物 |
| 第一财经 YiMagazine | 商业深度、生活方式 | 消费、品牌 |
| 财新 | 政策、金融、宏观 | 行业政策、宏观判断 |

**使用规则**：
- 引用具体数据时标注报道日期
- 区分"事实"与"记者观点"
- 报道中的人物语录必须可追溯到原始视频/音频

## 金句素材库

### 一、刘润过往文章金句

**来源**：
- 公众号「刘润」历史文章（2014 年至今）
- 《5分钟商学院》音频文稿（得到 App）
- 《底层逻辑》《5分钟商学院·基础篇》
- 《关于鸿蒙我想说的 32 句话》原文

**使用规则**：
- **可参考风格，不直接照搬**——避免重复
- 引用刘润本人原话时标注出处
- 提炼"句式模板"而非"具体句子"

### 二、其他商业作家金句

| 来源 | 风格 | 适合借鉴 |
|------|------|----------|
| 华与华方法论 | 超级符号、谚语化 | 短句、朗朗上口 |
| 稻盛和夫 | 哲学化、利他主义 | 价值观表达 |
| 巴菲特致股东信 | 朴素、长期主义 | 反常识表达 |
| 纳瓦尔宝典 | 杠杆、复利 | 概念拆解 |

**使用规则**：
- 引用其他作家观点时必须标注
- 不暗示是刘润本人观点

### 三、金句提炼方法

写作时按以下步骤提炼金句：
1. **先写平淡版**（"今天天气很好适合出门"）
2. **压缩到 15 字内**（"好天气，该出门"）
3. **加对仗/类比/反问**（"好天气不出门，辜负的不仅是天"）
4. **打磨到朗朗上口**（节奏感）

## 数据时效性标注规则

**强制要求**：所有长文中引用的数据必须标注时效。

**正确示例**：
> "截至 2024 年 9 月，拼多多市值约 2000 亿美元。"
> "根据中信证券 2024 年 3 月研报，2023 年中国新茶饮市场规模约 1500 亿元。"

**错误示例**：
> "拼多多市值很大" ❌（无数据）
> "拼多多市值 2000 亿美元" ❌（无时间）
> "拼多多最新市值 2000 亿美元" ❌（"最新"会随时间变化）

**刘润风格标注法**：
- 在数据后用括号或破折号补充"截至 XXXX 年 X 月"
- 第一次出现时给出完整来源（数据 + 机构 + 时间）
- 后续出现时简写"截至同源数据"或"同前"

## 信息验证检查清单

### 商业数据
- [ ] 是否有可靠出处（公司公告/权威媒体/知名研究机构）？
- [ ] 是否标注时效（"截至XXXX年X月"）？
- [ ] 是否经过 2 个独立来源验证？
- [ ] 单位是否明确（元/亿美元/万元）？

### 案例素材
- [ ] 故事是否有时间、地点、人物、决策 4 要素？
- [ ] 关键决策点是否可追溯到原始来源（视频/书籍/演讲）？
- [ ] 是否标注信息时效？

### 企业家语录
- [ ] 是否标注场合（会议/采访/演讲）？
- [ ] 是否标注时间（年月日）？
- [ ] 是否可追溯到原始视频/音频/书籍？

### 金句引用
- [ ] 引用其他作家时是否标注出处？
- [ ] 是否避免暗示是刘润本人观点？
- [ ] 是否避免直接照搬刘润原句？

```markdown
- **核心事实**：
  - 时间：
  - 地点：
  - 人物：
  - 决策：
- **可借鉴角度**：
  - 故事框：
  - 比方：
  - 金句：
- **数据支撑**：[截至 XXXX 年 X 月]
- **限制**：仅供创作参考，避免照搬

## 案例 2：[案例名]
...
```

```markdown
# 数据汇总

## 数据 1：[指标名]

- **数值**：[XXX]

- **适用范围**：[A股/港股/美股/行业整体]
- **可引用角度**：
  - 趋势判断
  - 同业对比
  - 比例说明

...
```

```markdown
# 金句素材库

## 主题：[主题名]

- **原句**："[刘润/其他作家 原话]"
- **出处**：[具体文章/书籍/演讲]
- **句式模板**：[提炼出可复用的句式结构]
- **可应用场景**：[同类主题的其他案例]

...
```

### facts-check.md（事实核查报告）

```markdown
# 事实核查报告

## 已验证事实
| 事实 | 来源 1 | 来源 2 | 时效 | 状态 |
|------|--------|--------|------|------|
| ... | ... | ... | ... | ✅ |

## 待核实项
- [事实 A]：来源 [X] 单源，待补充
- [事实 B]：与来源 [Y] 冲突，需进一步核查

## 数据时效性
- [内容 1]：截至 2024 年 Q3
- [内容 2]：截至 2024 年 12 月

## 风险提示
- [风险 1]：本篇涉及 [X] 行业数据，[Y] 来源与其他来源偏差较大
```

## 8 大心法在调研中的体现

| 心法 | 调研要求 |
|------|----------|
| **同理心** | 调研时先想"读者会关心什么问题"——主动替读者问 |
| **对象感** | 调研材料中所有"大家"在金句里必须改写为"你" |
| **君子自污** | 案例素材标注"非完美案例"——承认不足 |
| **逻辑势能 SCQA** | 调研输出按 S/C/Q/A 分类——直接对接大纲 |
| **5商派 SCA++** | 调研时标注"场景导入素材""打破认知素材" |
| **3 种结构** | 调研时按 3 段式/10 点式/32 条 分别准备素材 |
| **单反聚焦** | 同一案例准备 3 种角度（故事/举例/比方） |
| **用词推敲** | 数据表述时反复推敲——"截至"比"目前"更准 |
