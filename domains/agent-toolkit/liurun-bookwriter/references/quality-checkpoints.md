# 质量检查清单

每篇文章完成后必须通过的验证清单。

---

## 每篇 QC（12 项）

### 结构检查（4 项）

- [ ] **结构类型匹配**：开头元数据中标注的结构类型（3段式/10点式/32条/5商派）与正文实际结构一致
- [ ] **段落数正确**：
  - 3 段式：恰好 5 段（§01 引言 + §02/§03/§04 主体 + §05 最后的话）
  - 10 点式：恰好 11 段（1 开头 + 10 点 + 1 收束）
  - 32 条：恰好 32 条（第01句 到 第32句）
  - 5商派 SCA++：恰好 5 步
- [ ] **同理心开头**：开头 3 段内出现同理心锚点（"你可能正在......"）
- [ ] **收束**：3 段式和 10 点式必须有"最后的话"/"收束"段；32 条不需要（克制本身就是结构）

### 风格检查（5 项）

- [ ] **无禁用词**：见 style-dna.md 禁用词表
  - 无"综上所述"、"值得注意的是"、"接下来我们将"
  - 无"大家"（零容忍）
  - 无"在当今这个时代"、"随着...的发展"
  - 无商业黑话："赋能"、"抓手"、"底层逻辑"、"打通"
- [ ] **"我"频率**：每千字 ≥ 3 次
- [ ] **"你"频率**：每千字 ≥ 8 次（刘润标志性）
- [ ] **"大家"**：= 0
- [ ] **金句密度**：每千字 ≥ 2 句

### 内容检查（3 项）

- [ ] **故事/例子/比方至少 1 个**：每篇文章必须至少使用 1 个故事框、举例框或比方框
- [ ] **金句框至少 1 个**：每篇文章必须至少 1 个金句框
- [ ] **SCQA 节点标注**：3 段式 + ASC 显式标注至少 1 个 SCQA 节点

### 内容块频率（按结构类型）

| 结构 | 同理心 | 自污 | 金句 | 故事 | 举例 | 比方 | 推敲 |
|------|--------|------|------|------|------|------|------|
| 3 段式 | 1-2 | 1 | 每段 1 | 1-2 | 1-2 | 1-2 | 0-1 |
| 10 点式 | 1（开头） | 0-1 | 每点 1 | 3-5 | 2-3 | 2-3 | 0-1 |
| 32 条 | 0-1 | 1（开头） | 每条 1 | 0-1 | 5-10 | 0-2 | 0 |
| 5商派 SCA++ | 1-2 | 0-1 | 每步 1 | 1-2 | 2-3 | 1-2 | 0-1 |

---

## 全文 QC（10 项）

### 全局结构（4 项）

- [ ] **元数据块完整**：创作者、出处栏目、发布日期、结构类型、SCQA 变体、目标读者、核心洞察
- [ ] **结构类型正确**：3段式/10点式/32条/5商派 之一，与正文一致
- [ ] **SCQA 变体标注**：在元数据或文章开头标注
- [ ] **核心洞察清晰**：一句话说清这篇想讲什么

### 一致性（3 项）

- [ ] **人称一致**：始终用 "我" + "你"，不用 "大家"
- [ ] **风格统一**：全篇不出现"综上所述"、"值得注意的是"等禁用词
- [ ] **callout 格式统一**：同理心框、自污框、金句框、故事框、举例框、比方框、推敲框都用 `> **类型**：内容` 格式

### 内容深度（2 项）

- [ ] **单反聚焦**：核心观点至少用 2 种技法展开（讲故事/举例子/打比方/给金句）
- [ ] **逻辑势能清晰**：SCQA 节点贯穿全文

### 交付质量（1 项）

- [ ] **第一个 H1 是标题**：确保长文标题正确
- [ ] **元数据块完整**：创作者/出处栏目/结构类型/SCQA 变体/发布日期 齐全

## 3 种结构独立 QC profile

### 3 段式 profile

| 检查项 | 阈值 |
|--------|------|
| 段数 | 恰好 5 段（§01-§05） |
| 每段字数 | 400-600 字 |
| "我" 频次 | ≥ 6 |
| "你" 频次 | ≥ 10 |
| 金句数 | ≥ 3 |
| 故事/例子/比方 | 至少 3 个 |
| SCQA 节点 | 显式标注至少 1 个 |
| 收束段 | 必须有"最后的话"段 |

### 10 点式 profile

| 检查项 | 阈值 |
|--------|------|
| 段数 | 恰好 11 段（1 开头 + 10 点 + 1 收束） |
| 每点字数 | 200-350 字 |
| "我" 频次 | ≥ 4 |
| "你" 频次 | ≥ 8 |
| 金句数 | ≥ 5 |
| 故事/例子/比方 | 至少 5 个 |
| 环环相扣 | 每点结尾承接下点开头 |
| 收束段 | 必须有"收束"段 |

### 32 条 profile

| 检查项 | 阈值 |
|--------|------|
| 条数 | 恰好 32 条 |
| 每条字数 | 60-100 字 |
| "我" 频次 | ≥ 2 |
| "你" 频次 | ≥ 4 |
| 金句数 | ≥ 8（每条都是金句） |
| 故事/例子 | 5-10 个 |
| 不要"最后的话"段 | ✅（克制本身是结构） |
| 开头必须有"缘起" | 解释为什么是 32 条 |

### 5商派 SCA++ profile

| 检查项 | 阈值 |
|--------|------|
| 步骤数 | 恰好 5 步（场景-认知-逻辑-举一反三-回顾） |
| 每步字数 | 300-500 字 |
| "你" 频次 | ≥ 8 |
| 场景导入要具体 | 必含"你" + 具体场景 |
| 打破认知用设问 | 必含连续设问 |
| 举一反三 2-3 例 | 必含 2-3 个其他场景 |

## TDD 铁律

**违反以下任何一条 = 删除重写**

- 开头有同理心锚点
- "你" 频率 ≥ 每千字 8 次
- "大家" = 0
- 至少 1 个同理心框
- 至少 1 个金句框
- 至少 1 个故事/例子/比方框
- 结尾有收束（32 条除外）
- 无禁用词
- 句长 ≤ 45 字
- 段落数正确（按结构类型）
- SCQA 节点贯穿
- 元数据块完整

## Rationalization Table

Agent 在压力下会找借口跳过规则：

| 借口 | 现实 |
|------|------|
| "同理心开头太长了，不重要" | 同理心是刘润最重要的基本功。没同理心 = 失败。 |
| "'大家'也就一两次，没关系" | "大家" = 零容忍。一票否决。 |
| "这章没有故事素材可用" | 没故事就编一个，没例子就举一个，没比方就找一个。 |
| "32 条凑不齐，31 条也行" | 不行。32 条 = 克制而严谨，凑不够 = 改用 3 段式。 |
| "金句可以放到下一章写" | 不行。每千字 ≥ 2 金句是刘润的核心标识。 |
| "禁词只有一两次，不影响" | 一个禁词 = 一个红旗。改掉。 |
| "句长超过 45 字，但意思表达得更清楚" | 短句 + 中等长句是节奏。不是 100% 短句，也不是 100% 长句。 |
| "5 商派太复杂了，我用 4 步就行" | 5 步 = 5 分钟商学院的招牌。漏一步 = 不是 5商派。 |
| "10 点凑不够 10 点" | 不行。10 点式必须 10 点。凑不够改用 5 点式或 3 段式。 |
| "自污太多会显得没自信" | 君子自污 = 消除恶意。不自污 = 招黑。 |
| "商用黑话'赋能'很常见" | 刘润追求"短"、"准"，黑话是反义词。必须改。 |

## Red Flags

看到以下信号，停止写作，回到文章开头重来：

- 开头是"在当今这个...时代"、"随着...的发展"、"近年来..."
- 用了"综上所述"、"值得注意的是"、"接下来我们将"
- 用了"大家"
- 用了"赋能"、"抓手"、"底层逻辑"、"打通"
- 单句超过 45 字（连续 30+ 字句超过 5 个）
- "你" 出现频率 < 6 次/千字
- 全篇没有"我"或"我的"
- 没有同理心框
- 没有金句框
- 没有故事/例子/比方框
- 32 条文章不是 32 条
- 10 点式不是 10 点
- 3 段式不是 5 段（多了或少了）
- 结尾是"以上就是本章内容"、"感谢阅读"
- 表格没有 callout 标注
- 元数据块缺失
