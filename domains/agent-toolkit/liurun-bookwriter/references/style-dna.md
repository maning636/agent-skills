# 写作风格 DNA

从刘润 28 年商业写作经验（特别是《我这28年的写作心法》一文）中提取的完整写作风格规则。

---

## 一、8 大心法（核心心智模型）

### 心法 1：同理心（最重要的基本功）

**核心**：心里装的不是 "我"，是 "你"。

**应用规则**：
- 开头前 3 段必须把读者此刻可能的状态写出来
- 用同理心锚点："你可能正在......"、"你不妨想想......"
- 主动替读者问出他心中想问的问题
- 帮读者消除卡顿，像导游一样领着读者走

**量化指标**：每千字 "你" 出现 ≥ 8 次

**刘润原话**：
> "你可能正在下班高峰的浪潮之中，拖着疲惫不堪却又不肯服输的身躯，希望用碎片化的时间学习一点感兴趣的知识。"
> "你可能正在沙发上葛优躺，翻动着这个叫刘润的人的文章。"
> "对啊，为什么为什么为什么？这样一来，读者的思绪就被一只看不见的手牵着走了。"

### 心法 2：对象感

**核心**：写给"马云"看。

**应用规则**：
- 用 "你" 不用 "大家"
- 想象具体的人坐在你对面
- 大量使用 "你" 营造对话感
- 必要时可用 "他" / "她" 替代（指代具体人）

**量化指标**：「大家」= 0 次

**刘润原话**：
> "同学们啊，你们写文章的时候要当作，这篇文章是写给马云看的。"
> "为什么？因为'大家'这个词，是没有对象感的，它指代不了任何一个特定的人。"

### 心法 3：幽默感（君子自污）

**核心**：盛气凌人换不来善意。

**应用规则**：
- 把好事给对方，把坏事留给自己
- 自嘲式开场（"我斗胆"、"请您给掌掌眼"）
- 开自己的玩笑
- 主动暴露自己的"不专业"

**专属 callout**：自污框（> **先认个错**：...）

**刘润原话**：
> "中国有句老话叫，君子自污。什么意思？就是你浑身雪白地出门，就会有人忍不住冷不丁地往你身上泼脏水。"
> "请您给掌掌眼，我写了这么一堆破玩意儿，您觉得我写明白了吗？"

### 心法 4：逻辑势能 SCQA

**核心**：飞流直下三千尺，倾泻而下。

**应用规则**：
- 写之前先选定 SCQA 变体
- 在文中显式标注（用 callout 标记 S/C/Q/A 节点）
- 3 种结构有不同默认：3段式→ASC、10点式→QSCA、32条→CSA

**SCQA 三变体**：

| 变体 | 顺序 | 适用 | 范例 |
|------|------|------|------|
| **ASC** 开门见山式 | 答案-背景-冲突 | 工作报告、建议书 | "把提成制改为奖金制" |
| **CSA** 突出忧虑式 | 冲突-背景-答案 | 制造焦虑、热点回应 | "你按按倒数第三根肋骨......果然很痛吧" |
| **QSCA** 突出信心式 | 问题-背景-冲突-答案 | 大问题大方案、案例 | 马斯克火星移民演讲 |

### 心法 5：5商派 SCA++

**核心**：抓住听众稍纵即逝的注意力。

**5 步流程**：
1. **场景导入**：把读者请进文字空间，导入身份和情绪
2. **打破认知**：用设问把读者思绪牵着走
3. **核心逻辑**：给出 A
4. **举一反三**：知识的其他用途
5. **回顾总结**：帮读者梳理，升华

### 心法 6：3 种结构

**3 段式**（最简单）：1 段引言 + 3 段主体 + 1 段"最后的话"

**10 点式**（珍珠项链）：1 开头 + 10 个环环相扣的点

**32 条**（克制严谨）：32 句话

### 心法 7：观点表达（单反相机聚焦）

**核心**：一直打，一直打，打到透为止。

**4 种表达技法**：

| 技法 | 作用 | 关键 |
|------|------|------|
| **讲故事** | 让读者自己得出结论 | 关键在细节 |
| **举例子** | 降低认知成本 | 范例：小张在支付宝借了 1 万元 |
| **打比方** | 窥探两件事的本质 | 范例：品牌就像一个很大很大的碗 |
| **给金句** | 点睛之笔 | 范例："哪有从天而降的英雄，只有平凡人的挺身而出" |

**量化指标**：金句密度 ≥ 2 句/千字

### 心法 8：用词（游标卡尺拿捏）

**3 件事**：

1. **短**——马克·吐温：写短信比写长信更花时间
   - 范例："出租司机"而非 "出租车司机"
2. **准**——推敲（推 vs 敲）
   - 范例："陪伴"而非 "帮助"
3. **改**——改到 "打死我也不改了"
   - 范例：《5分钟商学院》2 万字 → 2、3 千字 → 1800 字

## 二、句式指纹

### 2.1 句长控制

- **目标**：单句 ≤ 45 字
- **节奏**：短句开路 + 中等长句叙述
- **可突破**：偶尔可以更短或更长，但要保持节奏

**示例**：
```
✅ 好：写作，最重要的......应该是"写"吧。

✅ 好：你可能正在下班高峰的浪潮之中，拖着疲惫不堪却又不肯服输的身躯，
        希望用碎片化的时间学习一点感兴趣的知识。

❌ 差：在当今这个时代，随着商业环境的快速变化，企业家们越来越需要具备
        战略思维、商业洞察和创新能力。
```

### 2.2 人称使用

- **"我"**：第一人称，高频（"我斗胆"、"我常常会"、"我忍不住"）
- **"你"**：第二人称，**更高频**（"你猜猜"、"你可能正在"、"你不妨"）
- **"大家"**：零容忍，必须替换为 "你" 或具体人名

**频率目标**：
- "我" ≥ 3 次/千字
- "你" ≥ 8 次/千字
- "大家" = 0

### 2.3 对话感

- 设问-回答-再设问-再回答
- 主动替读者问："为什么？怎么会这样呢？具体怎么做呢？"
- 立刻回答刚才的问题

**示例**：
```
✅ 好：为什么你去某些景点旅游就被疯宰，而在楼下菜市场买菜就不会呢？
        因为在销售公式里，销售=流量 × 转化率 × 客单价 × 复购率。
        景区的海鲜店流量和转化率基本固定，这辈子只跟你做一次生意，
        是单次博弈，所以他当然拼命提高客单价，宰死你为止。
```

### 2.4 节奏控制

- **短句开路**："写作，最重要的......应该是'写'吧。"
- **中等长句叙述**："你可能正在下班高峰的浪潮之中，拖着疲惫不堪却又不肯服输的身躯......"
- **金句收束**：用一句短而有力的话结束一段

## 三、词汇特征

### 3.1 高频词

- 你、我、我们、怎么、为什么、其实
- 不妨、你看、好了、是的、这叫
- 一句话、简单地来说、说白了
- 飞流直下三千尺、君子自污、推敲
- 有意思、有趣、好玩

### 3.2 推敲词（用词的精确选择）

| 推敲 | 不用 | 理由 |
|------|------|------|
| 出租司机 | 出租车司机 | "车"是多余的 |
| 陪伴 | 帮助 | 前者是朋友，后者是前辈 |
| 重复博弈 | 长期合作 | 前者更精确 |
| 飞流直下三千尺 | 很强的逻辑性 | 前者更有画面感 |
| 我斗胆 | 我建议 | 前者更自谦 |

### 3.3 故事/例子/比方的细节关键词

- 具体场景：地铁、午餐、沙发、深夜、机场
- 具体时间：1994 年、2019 年、上周、凌晨
- 具体数字：5 块钱、6000 万、33 万学员、600 字
- 具体动作：把烟头狠狠地丢在地上，碾了两脚

### 3.4 禁用词表

**继承自严谨文体**：

| 禁用 | 替代 |
|------|------|
| "综上所述" | 直接说 |
| "值得注意的是" | 直接说 |
| "接下来我们将进行" | "我们来" |
| "进行操作" | "做" |
| "实现功能" | "做到" |
| "强大的" / "革命性的" | 用具体事实替代 |

**刘润特定（更重要）**：

| 禁用 | 替代 |
|------|------|
| "大家" | "你" 或具体人名（零容忍） |
| "或许" / "可能" / "也许" | 直接断言（连续 3 次以上禁用） |
| "众所周知" / "不言而喻" / "显而易见" | 直接说 |
| "我们一起来看看" / "让我们一起" | 直接说 |
| "在当今这个时代" | 直接切入主题 |
| "随着...的发展" | 直接说 |
| "某种程度上" / "一定程度上" / "可以说是" | 直接说 |
| **商业黑话**：赋能、抓手、底层逻辑、打通 | 用刘润自己的话 |

### 3.5 商业黑话

刘润反而会避免使用的"商业黑话"：
- 赋能（用"帮助"或更具体的词）
- 抓手（用"切入点"或"方法"）
- 底层逻辑（用"根本"或具体解释）
- 打通（用"连接"或更具体的词）
- 闭环（用"完成"或更具体的词）

**理由**：刘润追求"短"、"准"，黑话是"绕"和"模糊"的反义词。

## 四、节奏控制

### 4.1 开头节奏

- 快速进入主题，前 2-3 段内给出核心信息
- 不用"在当今这个时代"式的水开头
- 默认用同理心锚点："你可能正在......"

### 4.2 主体节奏

- 故事 / 例子 / 比方 / 金句交替
- 每 300-500 字一个视觉断点
- 段落长度 2-5 句

### 4.3 结尾节奏

- 3 段式用"最后的话"升华
- 10 点式用"收束"段串起 10 点
- 32 条不用结尾（克制本身就是结构）
- 结尾句要短（≤ 20 字），有余味

### 4.4 段落长度

- 3 段式：每段 400-600 字
- 10 点式：每个点 200-350 字
- 32 条：每条 60-100 字

## 五、核心写作技巧

### 5.1 同理心锚点

用具体场景把读者此刻的状态写出来。

**模式**：`[你可能正在 / 你也许正在] + [具体的某时某地某状态]`

**示例**：
- "你可能正在下班高峰的浪潮之中，拖着疲惫不堪却又不肯服输的身躯......"
- "你可能正在沙发上葛优躺，翻动着这个叫刘润的人的文章。"
- "此时也许正是深夜，再刷一会儿，就一会儿，马上就睡了。"

### 5.2 设问-回答链

主动替读者问，再立刻回答。

**模式**：`[为什么？] + [因为......] + [那怎么办？] + [具体的解法]`

**示例**：
> "为什么你去某些景点旅游就被疯宰，而在楼下菜市场买菜就不会呢？
> 因为......
> 那怎么办？
> 淘宝的差评机制，把单次博弈变成了重复博弈。"

### 5.3 故事-细节-画面

讲一个故事时，关键在细节。

**模式**：`[动作] + [细节修饰] + [情绪]`

**示例对比**：
```
❌ 差：他站起身来，走向战场。
✅ 好：他抽完了最后一口烟，把烟头狠狠地丢在了地上，站起身来，碾了两脚，
       径直走向了战场。
```

### 5.4 举例-小张式

用具体的人（小张、小李）讲一个具体的故事。

**模式**：`[小张是什么人] + [他遇到了什么] + [具体怎么做] + [结果]`

**示例**（小张在支付宝借了 1 万元的故事）：
> "小张是支付宝的客户，有很高的芝麻信用分，向蚂蚁用年息 10%，借了 1 万元。
> 蚂蚁找到银行说：我们用科技（大数据，人工智能等等）评估过了，这是好客户，可以借。
> 我们合作吧：我出 1% 的资金，你出 99%；10% 的利息，一人一半。"

### 5.5 比方-窥探本质

把一件抽象的事"翻译"成一件贴近生活的事。

**模式**：`[抽象的 X] + [就像] + [贴近生活的 Y]`

**示例**：
> "品牌就像一个容器，一个很大很大的碗。里面的东西越多，这个容器就越稳。
> 打造品牌的过程中，做的各种各样的事儿，其实就是为了往这个容器里放三样东西。
> 第一件叫了解，第二件叫偏好，第三件叫信任。"

### 5.6 金句-朗朗上口

金句相对好理解，就是一句听上去朗朗上口、一下子打动人心的话。

**金句类型**：
- **玩笑类**："事已至此，先吃饭吧。""有空早点睡，没事多赚钱。"
- **情绪类**："其实大部分人，都已经见完了彼此的最后一面了。""考试过滤掉了学渣，却过滤不掉人渣。"
- **辩证类**："一流的人才雇佣一流的人才，二流的人才雇佣三流的人才。""多少的好答案，正在等一个好问题。"

**积累方法**：手机备忘录收集，看到好的就记下来。

## 六、内容模块格式

### 6.1 同理心框

> **你在想什么**：[读者此刻的疑问]
>
> [列出 1-2 个疑问，然后说"我们一个一个来聊"]

### 6.2 自污框

> **先认个错**：[自嘲式开场]
>
> [降低姿态，然后进入主题]

### 6.3 金句框

> **金句**：[一句朗朗上口的话]
>
> [可有可无的注解]

### 6.4 故事框

> **故事**：[一个具体场景 + 细节]
>
> [这个故事要说明的道理]

### 6.5 举例框

> **举例**：[小张式具体案例]
>
> [这个例子要说明的道理]

### 6.6 比方框

> **比方**：[X 就像......]
>
> [解释为什么这么比]

### 6.7 推敲框

> **推敲**：[原文] vs [改后]
>
> [为什么这么改]

## 七、风格标尺

| 维度 | 刘润位置 | 备注 |
|------|----------|------|
| 整体语气 | 70-80% 口语 | "你看"、"其实"、"是的" |
| 抽象 vs 具体 | 70-80% 具体 | 用小张、用数字 |
| 谨慎 vs 断言 | 有体验就断言 | 动态 |
| 学术 vs 通俗 | 80-90% 通俗 | 极少用术语 |
| 长句 vs 短句 | 70% 短句 + 30% 中等长句 | 不是 100% 短句 |
| 铺垫 vs 结论先行 | 结论先行 | 但有同理心铺垫 |
| 我 vs 你 | "你" 占比更高 | 对象感 |

## 八、风格量化指标总览

| 指标 | 阈值 | 来源 |
|------|------|------|
| 句长 | ≤ 45 字 | 商业长文节奏 |
| "我" 频率 | ≥ 3 次/千字 | 第一人称 |
| "你" 频率 | ≥ 8 次/千字 | 对象感 |
| "大家" | = 0 | 零容忍 |
| 金句密度 | ≥ 2 句/千字 | 观点表达 |
| 同理心锚点 | 开头 3 段内必出现 | 同理心 |
| 故事/例子/比方 | 每段至少 1 个 | 观点表达 |
| SCQA 节点 | 显式标注至少 1 个 | 逻辑势能 |
