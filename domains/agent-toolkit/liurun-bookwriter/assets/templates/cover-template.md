# 长文封面模板

用于刘润风格商业长文的封面自动生成。从 Markdown 文件开头提取元数据。

**核心设计原则**：
- 字段精简：只保留商业长文需要的关键信息（出处、日期、结构、洞察）
- 结构对应：3 段式 / 10 点式 / 32 条 / 5商派 各有专属封面变体
- 形式统一：所有变体使用同一套元数据字段，保证下游 PDF 生成一致性

---

## 文件开头元数据格式

```markdown
# [长文标题]

[副标题，可选]

**创作者**: 刘润
**出处栏目**: [公众号「刘润」/ 视频号 / 5分钟商学院 / 等]
**发布日期**: YYYY-MM-DD
**结构类型**: 3段式 / 10点式 / 32条 / 5商派
**SCQA 变体**: ASC / CSA / QSCA / 无
**目标读者**: [商业读者 / 创业者 / 管理者 / 投资人]
**核心洞察**: [一句话说清这篇想讲什么]
```

## Type A: 3 段式封面

适用：商业评论、方法论文章（1500-2500 字）

```markdown
# [长文标题]

[副标题：一句金句或核心洞察]

**创作者**: 刘润
**出处栏目**: 公众号「刘润」
**发布日期**: YYYY-MM-DD
**结构类型**: 3段式
**SCQA 变体**: ASC
**目标读者**: 创业者 · 商业读者
**核心洞察**: [一句话讲清楚本文的核心商业洞察]

> **金句**：[一句能拿走反复读的金句]

---

本文为公众号「刘润」原创

---

[正文 §01 引言 / §02 第一个核心论点 / §03 第二个核心论点 / §04 第三个核心论点 / §05 最后的话]
```

## 元数据提取规则

| Markdown 元素 | 封面位置 |
|-------------|---------|
| 第一个 `# H1` | 封面大标题 |
| H1 下方文本行 | 副标题 |
| `**创作者**:` | 作者署名 |
| `**出处栏目**:` | 栏目信息 |
| `**发布日期**:` | 发布日期 |
| `**结构类型**:` | 长文类型 |
| `**SCQA 变体**:` | 逻辑势能变体 |
| `**目标读者**:` | 读者画像 |
| `**核心洞察**:` | 一句话核心 |

## 8 大心法在封面中的体现

| 心法 | 体现 |
|------|------|
| **同理心** | 副标题用金句形式，直接对话读者 |
| **对象感** | 「目标读者」字段显式标注 |
| **君子自污** | 不用"震撼发布""重磅推出"等夸张词 |
| **逻辑势能 SCQA** | 元数据中显式标注 SCQA 变体 |
| **5商派** | Type D 封面为 SCA++ 5 步专门设计 |
| **3 种结构** | 3 种长文类型对应 3 种封面变体 |
| **单反聚焦** | 核心洞察"一句话说清" |
| **用词推敲** | 封面文案精炼到极致 |
