# 长文目录模板

用于罗振宇风格认知/启发/商业长文的目录自动生成。3 种结构对应 3 种目录格式。

**核心设计原则**：
- 段落编号唯一：罗胖60秒无编号（单段）；罗辑思维长文用 §NN；跨年演讲稿用"开场 + 第N段 + 收束"
- 结构对应：3 种结构对应 3 种目录格式
- 罗胖特征：跨年演讲稿必有"我是罗胖"开篇 + "我有一个启发"收束

---

## 目录生成规则

1. 从 `## §NN`、`## 第N段`、`## 收束` 三种格式的标题自动提取
2. 同一长文类型内部用统一格式
3. 罗振宇风格长文无 Part 分组（除非跨年演讲有"章"概念）
4. 不需要附录、阅读指南

---

## Type A: 罗胖60秒目录

适用：60 秒音频文稿、朋友圈启发式微文

```markdown
## 目录

CONTENTS

- 一段（60-150 字）：[金句标题]
```

**规则**：
- 恰好 1 段
- 段内必有 PEI 三段结构
- 不需要收束（克制本身是结构）
- 标题就是金句

---

## Type B: 罗辑思维长文目录

适用：罗辑思维公众号长文、得到 App 文章

```markdown
## 目录

CONTENTS

- §01 引子：[我是罗胖 / 你可能正在……]
- §02 第一个核心观点
- §03 第二个核心观点
- §04 第三个核心观点
- §05 收束：我有一个启发
```

**规则**：
- 5-7 段结构：1 引子 + 3-5 主体 + 1 收束
- §NN 编号必须连续：§01 → §05/§07
- §01 标题常含"我是罗胖"或"你可能正在"
- §05/末段 标题必须含"启发"或"启示"

**变体（6-7 段）**：
```markdown
## 目录

CONTENTS

- §01 引子：[我是罗胖 / 你可能正在……]
- §02 第一个核心观点
- §03 第二个核心观点
- §04 第三个核心观点
- §05 第四个核心观点
- §06 第五个核心观点（可选）
- §07 收束：我有一个启发
```

---

## Type C: 跨年演讲稿目录

适用：「时间的朋友」跨年演讲、《文明之旅》长文

```markdown
## 目录

CONTENTS

- 开场：我是罗胖
- 第一段：[故事主题 1]
- 第二段：[故事主题 2]
- 第三段：[故事主题 3]
- 第四段：[故事主题 4]
- 第五段：[故事主题 5]
- 收束：我有一个启发
```

**规则**：
- 必有"开场：我是罗胖"段
- 必有"收束：我有一个启发"段
- 主体 3-5 段
- 编号必须连续：第一段 → 第N段
- 每段标题应是动词驱动的金句

**变体（含 18 字心法版块）**：
```markdown
## 目录

CONTENTS

- 开场：我是罗胖
- 第一段：[故事主题 1]
- 第二段：[故事主题 2]
- 第三段：[故事主题 3]
- 第四段：18 字心法（"一具体，就深刻；一行动，就创新；一困惑，就出门"）
- 第五段：[故事主题 4]
- 收束：我有一个启发
```

---

## PDF 目录深度

**`export_pdf.py --toc-depth`** 设置：
- 罗胖60秒：深度 1（覆盖 `## 一段`）
- 罗辑思维长文：深度 2（覆盖 `## §NN`）
- 跨年演讲稿：深度 2（覆盖 `## 第N段`）

**统一使用**：`pandoc --toc --toc-depth=2`

---

## 目录样式建议

```markdown
## 目录

CONTENTS

§01 引子：我是罗胖 .................. 1
§02 长期主义：不是熬时间 ............ 3
§03 一具体，就深刻 .................. 5
§04 一行动，就创新 .................. 8
§05 收束：我有一个启发 .............. 11
```

pandoc 会自动用点号连接标题与页码，无需手动写。

## 长文类型与目录格式对应表

| 长文类型 | 段数 | 编号格式 | 收束段 | 适用场景 |
|---------|------|----------|--------|----------|
| 罗胖60秒 | 1 | 一段 | 不要 | 60秒音频、朋友圈 |
| 罗辑思维长文 | 5-7 | §NN | 必须（"启发"）| 公众号、得到 App |
| 跨年演讲稿 | 5-7 | 第N段 | 必须（"启发"）| 跨年演讲、《文明之旅》|

## 12 大心法在目录中的体现

| 心法 | 体现 |
|------|------|
| **躬身入局** | 跨年演讲必有"我是罗胖"开场 |
| **长期主义** | 目录标题常含"1000天"、"长期" |
| **启发式输出** | 收束段标题必含"启发" |
| **一具体，就深刻** | 目录标题常含具体数字 / 时间 / 人物 |
| **一行动，就创新** | 目录标题用动词（"走"、"迈"、"躬身"）|
| **一困惑，就出门** | 跨年演讲常含"走访"、"调研"标题 |
| **故事细节** | 目录标题含具体人物 / 事件 |
| **金句主义** | 目录标题本身就是金句 |
| **动词驱动** | 段标题用动词（"躬身"、"迈"、"走"、"磕"）|
| **谦卑自嘲** | 开场段标题含"罗胖"自指 |
