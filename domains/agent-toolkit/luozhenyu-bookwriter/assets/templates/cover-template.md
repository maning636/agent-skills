# 长文封面模板

用于罗振宇风格认知/启发/商业长文的封面自动生成。从 Markdown 文件开头提取元数据。

**核心设计原则**：
- 字段精简：只保留罗振宇风格需要的关键信息（出处、日期、结构、洞察、必含心法）
- 结构对应：罗胖60秒 / 罗辑思维长文 / 跨年演讲稿 3 种结构各有专属封面变体
- 形式统一：所有变体使用同一套元数据字段，保证下游 PDF 生成一致性
- 罗胖特征：必含 "我是罗胖" / "我有一个启发" 标识

---

## 文件开头元数据格式

```markdown
# [长文标题]

[副标题，可选]

**创作者**: 罗振宇
**出处栏目**: [罗辑思维 / 得到 App / 罗胖60秒 / 时间的朋友 / 文明之旅]
**发布日期**: YYYY-MM-DD
**结构类型**: 罗胖60秒 / 罗辑思维长文 / 跨年演讲稿
**SCQA 变体**: TQA / CAA / PEI / 无
**目标读者**: [大众读者 / 创业者 / 终身学习者 / 商业读者]
**核心洞察**: [一句话说清这篇想讲什么]
**必含心法**: [躬身入局 / 长期主义 / 启发式输出 / 一具体就深刻 / 一行动就创新 / 故事细节 / 金句主义]
```

## Type A: 罗胖60秒封面

适用：每日 60 秒音频文稿、朋友圈启发式微文（60-150 字）

```markdown
# [一句话金句标题]

[副标题：一句话核心启发]

**创作者**: 罗振宇
**出处栏目**: 罗胖60秒
**发布日期**: YYYY-MM-DD
**结构类型**: 罗胖60秒
**SCQA 变体**: PEI
**目标读者**: 大众读者 · 终身学习者
**核心洞察**: [一句话讲清楚本条 60 秒的启发]
**必含心法**: [至少 2 个：故事细节 / 启发式输出 / 金句主义]

> **金句**：[一句能拿走的金句]

---

本文为「罗胖60秒」原创

---

[正文：单段 60-150 字，含 P 现象 → E 解释 → I 启发]
```

**关键约束**：
- 整段不超过 150 字
- 必有具体时间/地点/数字
- 必含"我有一个启发……"
- 必含 1 个对仗式或数字式金句
- 禁用"大家"，"我们"出现 ≤ 1 次

## Type B: 罗辑思维长文封面

适用：罗辑思维公众号长文、得到 App 文章（2000-4000 字）

```markdown
# [长文标题]

[副标题：一句金句或核心启发]

**创作者**: 罗振宇
**出处栏目**: [罗辑思维 / 得到 App / 启发 / 文明之旅]
**发布日期**: YYYY-MM-DD
**结构类型**: 罗辑思维长文
**SCQA 变体**: TQA / CAA
**目标读者**: 终身学习者 · 创业者
**核心洞察**: [一句话讲清楚本篇的启发]
**必含心法**: [至少 3 个：躬身入局 / 一具体就深刻 / 故事细节 / 启发式输出 / 金句主义]

> **金句**：[一句能拿走反复读的金句]

---

本文为 [出处栏目] 原创

---

## 本文导览

1. [第 1 段的标题]
2. [第 2 段的标题]
3. [第 3 段的标题]
4. [第 4 段的标题]
5. [第 5 段/收束段的标题]

[正文：引子 + 3-5 主体段 + 收束]
```

**关键约束**：
- 5-7 段结构
- 至少 1 个躬身入局框
- 至少 1 个故事细节框（含具体时间/地点/数字）
- 至少 1 个启发框
- 至少 1 个金句框
- 禁用"大家"，"我们" ≤ 5 次/千字

## Type C: 跨年演讲稿封面

适用：「时间的朋友」跨年演讲、《文明之旅》长文（8000-15000 字）

```markdown
# [长文标题]

[副标题：跨年的启发 / 18 字心法]

**创作者**: 罗振宇
**出处栏目**: 时间的朋友（[年份] 跨年演讲）/ 文明之旅
**发布日期**: YYYY-MM-DD
**结构类型**: 跨年演讲稿
**SCQA 变体**: TQA
**目标读者**: 大众读者 · 终身学习者
**核心洞察**: [一句话讲清楚本场跨年的核心主题]
**必含心法**: [至少 5 个：躬身入局 / 长期主义 / 一具体就深刻 / 一行动就创新 / 一困惑就出门 / 故事细节 / 金句主义]

> **金句**：[本场跨年的核心金句，含数字金句]

---

[罗振宇自嘲开场]

> **罗胖自嘲**："我是罗胖。"（不编减肥数字，保持克制真实）

---

## 本场导览

- 开场：我是罗胖
- 第一段：[标题]
- 第二段：[标题]
- 第三段：[标题]
- 第四段：[标题]
- 第五段：[标题]
- 收束：我有一个启发

[正文：开场 + 3-5 故事章节 + 收束 + 18 字心法]
```

**关键约束**：
- 必有"我是罗胖"开篇自嘲
- 必有 18 字心法之一出现（"一具体，就深刻" / "一行动，就创新" / "一困惑，就出门"）
- 至少 2 个数字金句（素材源可查：3652 条 / 11 场 / 523 个词条 / 1000 天 / 18 字心法级别）
- 至少 5 个故事细节（含具体时间/地点/人物/数字）
- 至少 2 个躬身入局框
- 至少 1 个长期主义框
- 收束必含"我有一个启发……"

## 元数据提取规则

| Markdown 元素 | 封面位置 |
|-------------|---------|
| 第一个 `# H1` | 封面大标题 |
| H1 下方文本行 | 副标题 |
| `**创作者**:` | 作者署名 |
| `**出处栏目**:` | 栏目信息 |
| `**发布日期**:` | 发布日期 |
| `**结构类型**:` | 长文类型 |
| `**SCQA 变体**:` | 逻辑势能变体 |
| `**目标读者**:` | 读者画像 |
| `**核心洞察**:` | 一句话核心 |
| `**必含心法**:` | 心法清单 |

## 12 大心法在封面中的体现

| 心法 | 体现 |
|------|------|
| **躬身入局** | "必含心法" 字段常含"躬身入局" |
| **长期主义** | 跨年演讲稿必含"长期主义"心法标识 |
| **启发式输出** | 核心洞察字段用"启发"语义 |
| **一具体，就深刻** | 必有具体时间/地点/数字（封面元数据也算具体）|
| **一行动，就创新** | 行动召唤可在副标题体现 |
| **一困惑，就出门** | 调研时主动"出门"找资料 |
| **故事细节** | 封面 metadata 含具体发布日 + 出处栏目 |
| **金句主义** | 副标题必是金句形式 |
| **动词驱动** | 副标题用动词不用名词 |
| **谦卑自嘲** | 跨年演讲稿必有"罗胖自嘲"开篇 |
