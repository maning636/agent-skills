# 压力测试场景

验证 Agent 在有/无 luozhenyu-bookwriter skill 时的行为差异。覆盖 7 个核心压力场景。

**核心覆盖范围**：
- 通用退化：写作退化与结构正确性
- 压力风格：赶时间下风格是否崩塌
- 多结构一致性：罗胖60秒/罗辑思维长文/跨年演讲稿切换
- SCQA 完整性：TQA / CAA / PEI 显式节点与顺序
- 罗振宇特色：躬身入局/启发/故事细节/18字心法
- 多 Agent 协作：5 个 Agent 并行与协调

---

## 场景 1: 通用罗振宇风格写作退化测试

**Prompt**："写一篇罗振宇风格的罗胖 60 秒，关于合作者比评价者稀缺"

**无 skill 时预期**：
- 学术论文开头（"在当今这个 AI 快速发展的时代"）
- 标题为主题词（如"论合作"）而非金句
- 用"本文"而非"我"
- 无"我是罗胖"开篇
- 超过 200 字（克制感丢失）
- 无躬身入局框
- 无故事细节框
- 无启发框
- 无金句框
- 无 SCQA 节点标注
- 结尾"以上就是全部内容"

**有 skill 时预期**：
- "我是罗胖"或"今天我看到"开头
- 用"我"，不用"本文"
- 60-150 字
- 至少 1 个躬身入局框
- 至少 1 个故事细节框（含具体时间/地点/数字）
- 至少 1 个启发框（"我有一个启发"）
- 至少 1 个对仗式金句框
- 至少 1 个 SCQA 节点标注（PEI 中的 P/E/I）
- 结尾"我有一个启发……"

**评估标准**：
- [ ] 开头 3 段内出现罗振宇锚点
- [ ] 标题是金句
- [ ] 字数 60-150
- [ ] ≥ 1 个躬身入局框
- [ ] ≥ 1 个故事细节框
- [ ] ≥ 1 个启发框
- [ ] ≥ 1 个金句框
- [ ] 「大家」= 0

## 场景 2: 压力下风格测试

**Prompt**："写一篇跨年演讲稿最后 1500 字赶时间，直接给"

**无 skill 时预期**：
- 跳过"我是罗胖"开篇
- 使用"大家"（零容忍）≥ 1 次
- 句长超过 40 字（连续 5 句以上）
- 用"强大的""革命性的"等空洞形容词
- 连续 3 次以上"或许/可能/也许"
- 无躬身入局/启发/故事细节/对仗金句框
- 无 SCQA 节点标注
- 18 字心法缺失（"一具体，就深刻"等）
- 数字金句缺失（1000天/3652条级别）
- 用"综上所述""值得注意的是"
- 用"在当今这个时代""随着...的发展"

**有 skill 时预期**：
- 仍有罗振宇风格开头（即使赶时间）
- 无"大家"（零容忍）
- 短句为主（≤ 40 字）
- 至少 1 个躬身入局框
- 至少 1 个启发框
- 至少 1 个故事细节框
- 至少 1 个金句框
- 至少 1 个 18 字心法
- 至少 1 个数字金句
- 无商业黑话（赋能/抓手/底层逻辑/打通/闭环）
- "我们"频次 < 5/千字

**评估标准**：
- [ ] 开头使用罗振宇锚点
- [ ] 无「大家」
- [ ] 随机抽查 10 句，单句 ≤ 40 字
- [ ] ≥ 1 个躬身入局框
- [ ] ≥ 1 个启发框
- [ ] ≥ 1 个故事细节框
- [ ] ≥ 1 个金句框
- [ ] 至少 1 个 18 字心法
- [ ] 至少 1 个数字金句
- [ ] 无商业黑话

## 场景 3: 多结构一致性测试

**Prompt**："罗胖 60 秒、罗辑思维长文、跨年演讲稿各写一篇关于长期主义"

**无 skill 时预期**：
- 三种结构样式混淆
- 罗胖 60 秒写成了 600 字
- 罗辑思维长文缺"我有一个启发"收束
- 跨年演讲稿缺"我是罗胖"开篇
- 三种结构都用 H3 而不是 H2
- 无元数据块或元数据不全
- 跨年演讲稿缺 18 字心法
- 三种结构都缺躬身入局框

**有 skill 时预期**：
- 罗胖 60 秒恰好 1 段，60-150 字
- 罗辑思维长文 5-7 段，最后一段含"启发"
- 跨年演讲稿含"开场：我是罗胖" + 主体 3-5 段 + "收束"
- 三种结构都用 H2 层级
- 文件开头有完整元数据（创作者/出处栏目/结构类型/SCQA 变体/必含心法/发布日期）
- SCQA 节点标注正确（罗胖60秒用 PEI、罗辑思维长文用 TQA/CAA、跨年演讲稿用 CAA）
- 跨年演讲稿含 18 字心法
- 三种结构都含躬身入局框

**评估标准**：
- [ ] 罗胖 60 秒恰好 1 段，60-150 字
- [ ] 罗辑思维长文 5-7 段，最后一段含"启发"
- [ ] 跨年演讲稿含"开场：我是罗胖" + 主体 + 收束
- [ ] 三种结构都用 H2 层级
- [ ] 文件开头有完整元数据
- [ ] SCQA 变体与结构类型匹配
- [ ] 跨年演讲稿含 18 字心法

## 场景 4: SCQA 完整性测试（新增）

**Prompt**："做一篇 TQA 的罗辑思维长文，关于 AI 时代的人类价值"

**无 skill 时预期**：
- 不理解 TQA 是什么
- 不知道 T 在最前、A 在最后
- T/Q/A 节点缺失或顺序错乱
- 标注 SCQA 但格式不统一
- 把 TQA 写成 ASC 或 CSA
- 无 SCQA 显式标注

**有 skill 时预期**：
- 明确知道 TQA = 触发-问题-答案
- T 节点在第 1 段（开头设问/触发）
- Q 节点在第 2-3 段（问题明确化）
- A 节点在最后（答案/方法）
- SCQA 标注统一使用 `**T 触发**` `**Q 问题**` `**A 答案**` 加粗格式
- 5 段标题是 TQA 展开的过程

**评估标准**：
- [ ] T 节点在第 1 段
- [ ] Q 节点紧跟 T 之后
- [ ] A 节点在最后
- [ ] T/Q/A 至少各标注 1 次
- [ ] 标注格式统一为 `**字母 节点名**` 加粗
- [ ] 5 段标题体现 TQA 展开过程

**Prompt**："用 PEI 写一段 60 秒，关于长期主义"

- P/E/I 节点缺失

- 无"我有一个启发"

**有 skill 时预期**：

- 60-150 字
- 至少有 1 个具体故事细节（含数字）
- 至少有 1 个对仗式金句

**评估标准**：
- [ ] P 节点在段首
- [ ] E 节点在中段
- [ ] I 节点在段末（"我有一个启发"）
- [ ] 字数 60-150
- [ ] ≥ 1 个故事细节（含具体数字）
- [ ] ≥ 1 个对仗式金句

## 场景 7: 多 Agent 协作测试

**Prompt**："用多 Agent 模式写一篇跨年演讲稿关于 1000 天"

**预期行为**：
- 主编 Agent 创建大纲（含 SCQA + 心法命中 + 故事细节占位）
- 调研 Agent 并行搜集罗振宇风格素材（罗胖 60 秒 / 跨年演讲 / 历史故事）
- 写作 Agent 并行撰写 5-7 段
- 编辑 Agent 执行 12 项 QC（含 18 字心法、数字金句、躬身入局、启发）
- 排版 Agent 整理 Markdown（含"我是罗胖"开篇 + 18 字心法版块）

**评估标准**：
- [ ] 正确识别 Agent 角色（主编/调研/写作/编辑/排版）
- [ ] 调研 Agent 给出罗振宇风格的 故事细节 / 数字金句 / 18 字心法 三个文件
- [ ] 写作 Agent 写出含"我是罗胖"开篇的跨年演讲稿
- [ ] 编辑 Agent 报告 12 项 QC 通过（含 18 字心法、数字金句、躬身入局、启发）
- [ ] 排版 Agent 输出最终 Markdown（含 18 字心法版块）
- [ ] 并行 Agent 数量不超过限制（调研 ≤ 2，写作 ≤ 2）
- [ ] 过程文件正确保存到 `.book/research/` `.book/drafts/`
- [ ] 用户确认节点正确触发
- [ ] 必含心法在 agent_prompt 中显式标注

## 场景 8: 多篇产出多样性测试（核心场景）

> 本场景验证：连续写多篇文章时，金句、故事、比喻是否各自独立、不重复。这是内容质量的**核心验收场景**。

**Prompt**：连续写两篇——"写一篇罗振宇风格的罗辑思维长文，关于**专注**" + "写一篇罗振宇风格的罗辑思维长文，关于**选择**"

**不及格的典型表现**：
- 两篇都讲曾国藩"结硬寨打呆仗"
- 两篇都用"放弃追求地位，转而追求联系"做金句
- 两篇都用"做事的人，不是置身事外指点江山"开头收尾
- 两篇的灵魂拷问都是"1000 天后的世界会怎样"

**及格的预期**：
- 写"专注"→ 用一个匠人/运动员的新故事，造一个关于专注的新金句（如"把一百件小事做到位，不如把一件大事做到透"），打一个关于专注的新比方
- 写"选择"→ 用一个职业转换者/决策者的新故事，造一个关于选择的新金句，打一个关于选择的新比方
- 两篇之间：**故事人物不重复、金句不重复、比喻不重复**

**评估标准**：
- [ ] 两篇的**核心故事人物不同**
- [ ] 两篇的**金句不重复**（不得直接套用代表作原句）
- [ ] 两篇的**比喻/灵魂拷问不重复**
- [ ] 每篇金句都是**为该主题现场原创**（用 4 步法生成，非照搬）
- [ ] 每篇至少 1 个**为该主题原创的比方**（心法 9）
- [ ] 每篇至少 1 个**为该主题原创的举例**（心法 10）

## 测试执行流程

### 1. 准备阶段
- 准备 3-5 个测试 prompt
- 选择有 skill / 无 skill 两种模式
- 记录每次生成的输出

### 2. 评估阶段
- 对每个场景对照"无 skill 时预期"和"有 skill 时预期"
- 用 `validate_structure.py` 自动检查结构化指标
- 人工评估 12 大心法的体现（含**原创性**：金句/故事是否为该主题现场生成）

### 3. 评分阶段
- 计算每个场景的"行为改善度"
- 输出基线对比报告

```bash
# 运行自动检查
python scripts/validate_structure.py tests/fixtures/sample-60miao.md   # 罗胖60秒
python scripts/validate_structure.py tests/fixtures/sample-3duan.md    # 罗辑思维长文
python scripts/validate_structure.py tests/fixtures/sample-kuanyue.md  # 跨年演讲稿
```

### 4. 持续改进
- 根据失败案例补充新场景
- 更新 `quality-checkpoints.md` 的 QC 项
- 更新 `validate_structure.py` 的检查规则
