# 基线检查

记录在没有 luozhenyu-bookwriter skill 的情况下，Agent 面对罗振宇风格长文写作任务时的失败模式。用于对比验证 skill 激活前后的行为差异。

**核心覆盖范围**：
- 写作退化：开头、用词、人称、对象感
- 风格崩塌：禁用词、callout 缺失、SCQA 缺失
- 结构不一致：段数、SCQA 节点、心法命中
- 罗振宇标志性元素：躬身入局、启发、故事细节、数字金句

---

## 场景 A: 通用罗振宇风格写作退化

**提示词**："写一篇罗振宇风格的 60 秒，关于躬身入局"

**典型失败模式**：
1. 开篇是"在当今这个充满挑战的时代..." —— 零信息量开头
2. 用"本文"、"笔者"而非"我" —— 缺乏第一人称对话感
3. 没用"我是罗胖"开篇 —— 缺乏罗振宇标志
4. 没有"我有一个启发……" —— 缺乏启发式输出
5. 超过 200 字（60 秒被写成 600 字）—— 失去克制
6. 没有躬身入局框 —— 失去核心心法
7. 没有故事细节（含具体时间/地点/数字）—— 缺乏画面感
8. 无 SCQA 节点标注 —— 缺乏逻辑势能
9. 用"大家"作为对象 —— 零容忍的失败模式
10. 结尾是"以上就是全部内容"而非"我有一个启发" —— 缺乏收束

**评估标准**：
- [ ] 开头出现罗振宇锚点（"我是罗胖" / "你可能正在" / "今天我看到"）
- [ ] 用"我"不用"本文"
- [ ] 总字数 60-150 字
- [ ] 至少 1 个躬身入局框
- [ ] 至少 1 个故事细节框（含具体时间/地点/数字）
- [ ] 至少 1 个启发框（"我有一个启发"）
- [ ] 至少 1 个金句框
- [ ] 「大家」= 0
- [ ] 结尾有"我有一个启发……"

## 场景 B: 压力下风格崩塌

**提示词**："写一篇跨年演讲稿最后 1000 字赶时间，直接给"

**典型失败模式**：
1. 跳罗振宇风格开头（"我是罗胖"）
2. 使用"大家"（零容忍）—— 出现 ≥ 1 次
3. 句长超过 40 字（连续 5 句以上）—— 缺乏节奏感
4. 用"强大的""革命性的"等空洞形容词 —— 商业黑话
5. 连续 3 次以上"或许/可能/也许" —— 缺乏断言
6. 无躬身入局/启发/故事细节/对仗金句框 —— 缺乏 7 种 callout
7. 无 SCQA 节点标注 —— 缺乏逻辑势能
8. 用"在当今这个时代""随着...的发展" —— 禁用词
9. 18 字心法缺失（"一具体，就深刻"等）—— 跨年演讲稿必备
10. 数字金句缺失（1000天/3652条级别，须素材源可查）—— 跨年演讲稿必备
11. 缺乏具体时间/地点/数字的故事细节 —— 缺乏"一具体就深刻"
12. 用"综上所述""值得注意的是" —— 禁用词

**评估标准**：
- [ ] 仍有罗振宇风格开头（即使赶时间）
- [ ] 无"大家"
- [ ] 句长抽查 10 句，单句 ≤ 40 字（罗振宇比刘润更严）
- [ ] ≥ 1 个躬身入局框
- [ ] ≥ 1 个启发框
- [ ] ≥ 1 个故事细节框
- [ ] ≥ 1 个金句框
- [ ] 至少 1 个 18 字心法
- [ ] 至少 1 个数字金句
- [ ] 无"我们"频次 > 5/千字
- [ ] 无商业黑话

## 场景 C: 罗辑思维长文结构不一致

**提示词**："写一篇罗辑思维长文关于长期主义"

**典型失败模式**：
1. 段数错误（写 10 段或 3 段）—— 失去 5-7 段约束
2. 编号用"一、二、三"或"1."混用 —— 格式错误
3. 无"我是罗胖"开头 —— 缺失罗振宇标志
4. 无"我有一个启发"收束 —— 缺失启发式输出
5. 无元数据块或元数据不全（缺 SCQA 变体/必含心法）—— 元数据缺失
6. H1/H2/H3 层级混乱
7. 第一个 H1 不是长文标题
8. 没有任何一个躬身入局框 —— 失去核心心法
9. 没有具体数字金句（1000天、3652条级别）—— 失去罗振宇招牌
10. 故事细节都是模糊描述（"他做了一件事"）—— 缺乏"一具体就深刻"
11. 无 SCQA 节点标注（TQA 缺 T/Q/A）—— 缺乏逻辑势能

**评估标准**：
- [ ] 5-7 段（§01-§05/§07）
- [ ] 编号统一为"§NN"
- [ ] §01 含"我是罗胖"或类似开头
- [ ] 最后一段标题含"启发"或"启示"
- [ ] 文件开头有完整元数据（创作者/出处栏目/结构类型/SCQA 变体/必含心法/发布日期）
- [ ] 至少 1 个 SCQA 节点标注
- [ ] 至少 1 个躬身入局框
- [ ] 至少 1 个故事细节框（含具体时间/地点/数字）
- [ ] 至少 1 个启发框
- [ ] 至少 1 个金句框
- [ ] 至少 1 个数字金句

## 场景 D: 罗振宇风格识别度测试（新增）

**提示词**："写一段启发式内容，鼓励年轻人不要怕失败"

**典型失败模式**：
1. 用"同学们" / "朋友们" 代替"你" —— 对象感模糊
2. 用"加油！" / "我们一起努力" —— 鸡汤化
3. 缺乏"我"叙述，全是客观分析 —— 失去人格化
4. 用"或许""可能"作为核心论点的支撑 —— 缺乏断言
5. 没有具体故事（曾国藩 / 王阳明 / 商业案例）—— 缺乏画面感
6. 没有数字金句（1000天 / 3652条 / 18字心法级别）—— 失去罗振宇招牌
7. 缺少对仗式金句（"一XX，就XX" / "凡XX，皆XX"）—— 失去节奏
8. 缺少动词驱动（"躬身入局" / "迈小步" / "走远路"）—— 抽象化
9. 用"总之""综上所述" —— 严谨文体腔
10. 缺乏"我有一个启发……"的明确启发信号 —— 失去启发式输出

**评估标准**：
- [ ] 至少有 1 个对仗式金句
- [ ] 至少有 1 个数字金句
- [ ] 至少 3 个动词驱动（躬身/迈/走/磕/攒/入局）
- [ ] 至少有 1 个具体故事（含时间/地点/数字）
- [ ] 有"我有一个启发……"或"启示"
- [ ] 「大家」= 0
- [ ] 句长 ≤ 40 字

## 场景 E: SCQA 变体错用测试（新增）

**提示词**："用 TQA 写一篇关于 AI 焦虑的罗辑思维长文"

**典型失败模式**：
1. 不理解 TQA 是什么 —— 概念错误
2. 把 TQA 写成 ASC（先 A 后 C）—— 错用变体
3. T 节点缺失或不在开头 —— 缺乏"触发"信号
4. Q 节点缺失 —— 缺乏"问题"明确化
5. A 节点不在最后 —— 缺乏"答案"收束
6. SCQA 标注格式不统一（用 `**T触发**` 混用 `**T 触发**`）—— 缺乏纪律
7. 跨年演讲稿用 PEI（应默认 CAA）—— 错用变体
8. 罗胖60秒用 TQA（应默认 PEI）—— 错用变体

**评估标准**：
- [ ] 明确知道 TQA = 触发-问题-答案
- [ ] T 节点在 §01（开头触发）
- [ ] Q 节点在 §02-§03（问题明确化）
- [ ] A 节点在最后段（答案收束）
- [ ] SCQA 标注使用 `**T 触发**` `**Q 问题**` `**A 答案**` 加粗格式
- [ ] SCQA 变体与结构类型匹配（罗胖60秒→PEI、罗辑思维长文→TQA/CAA、跨年演讲稿→CAA）

## 评估流程

### 1. 无 skill 时行为采样

对每个场景，让 Agent 在**不加载 skill** 的情况下生成内容，记录典型失败模式。

### 2. 有 skill 时行为采样

对同一提示词，**加载 skill** 后再次生成，对照检查 12 项 QC。

### 3. 差异评分

| 维度 | 无 skill | 有 skill | 提升 |
|------|---------|---------|------|
| 罗振宇锚点开头 | 缺失 | 必现 | +100% |
| 「大家」 | 频繁 | = 0 | +100% |
| 结构准确性 | 随机 | 严格 | +80% |
| 躬身入局框 | 0 | ≥ 1 | +∞ |
| 启发框 | 0 | ≥ 1 | +∞ |
| 故事细节 | 模糊 | 具体（含数字）| +200% |
| 数字金句 | 0 | ≥ 1 | +∞ |
| 18 字心法 | 0 | ≥ 1（跨年稿）| +∞ |
| 金句密度 | < 1/千字 | ≥ 3/千字 | +300% |
| 句长合规率 | < 30% | ≥ 80% | +150% |
| **金句原创性** | 照搬代表作原句 | 为主题现场原创 | 质变 |
| **多篇多样性** | 篇篇讲曾国藩、用同一句金句 | 每篇换新故事/新金句/新比喻 | 质变 |

## 12 大心法对应的失败模式

| 心法 | 失败模式 | 检测点 |
|------|----------|--------|
| **躬身入局** | 无"做事的人" / 无躬身入局框 | callout 躬身入局框 |
| **长期主义** | 无 1000 天 / 长期视角 | 数字金句 |
| **启发式输出** | 无"我有一个启发" | 启发框 |
| **一具体，就深刻** | 故事全是模糊描述 | 故事细节框（时间/地点/数字）|
| **一行动，就创新** | 缺行动召唤 / 缺动词 | 动词驱动框 |
| **一困惑，就出门** | 缺"走访"/"调研"场景 | 故事细节中"出门"信号 |
| **故事细节** | 缺具体时间/地点/数字；**连续多篇用同一批案例** | 故事细节框 + 多样性 |
| **金句主义** | 缺对仗/数字/递进式金句；**直接套用代表作原句** | 金句密度 + 原创性 |
| **打比方** | 无原创比喻，抽象概念没有具象化 | 比方框 |
| **举例降认知** | 无具体人物的具体选择 | 举例框 |
| **动词驱动** | 抽象名词（"赋能"/"价值"）| 商业黑话检测 |
| **谦卑自嘲** | 无"我斗胆" / 无罗胖自嘲 | 自嘲框 / 跨年稿开篇 |

## 与 validate_structure.py 的对应

`scripts/validate_structure.py` 自动检查以下基线失败模式：

| 基线场景 | 自动化检查项 |
|---------|-------------|
| 场景 A 通用退化 | 罗振宇锚点开头、躬身入局框、启发框、字数（60-200）|
| 场景 B 压力崩塌 | 禁用词（「大家」= error）、句长（≤ 40）、18 字心法、数字金句 |
| 场景 C 结构不一致 | 段数、§NN 连续性、收束段"启发"标题 |
| 场景 D 风格识别度 | 对仗金句、数字金句、动词驱动 |
| 场景 E SCQA 变体 | 节点标注 + 变体与结构匹配 |

**使用方式**：
```bash
python scripts/validate_structure.py tests/fixtures/sample-60miao.md   # 罗胖60秒
python scripts/validate_structure.py tests/fixtures/sample-3duan.md    # 罗辑思维长文
python scripts/validate_structure.py tests/fixtures/sample-kuanyue.md  # 跨年演讲稿
```
