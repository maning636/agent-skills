# Agent 协作流程

多 Agent 协作的罗振宇风格认知/启发/商业长文创作规范。定义各 Agent 的职责、触发时机、协作方式与罗振宇风格特有的素材流转。

---

## Agent 角色定义

| Agent | 职责 | 触发时机 | 并行限制 |
|-------|------|----------|----------|
| 主编 Agent | 长文结构判断、进度协调、质量把关、用户确认、风格 DNA 把关 | Phase 0/1/2/6/8 | 单独执行 |
| 调研 Agent | 罗振宇风格素材搜集、故事细节、数据金句、历史/创业案例 | Phase 3-4 | 最多 2 个并行 |
| 写作 Agent | 长文撰写（按结构分点/段/条） | Phase 5 | 最多 2 个并行 |
| 编辑 Agent | 12 项 QC、3 种结构 profile、SCQA 检查、禁用词零容忍 | Phase 6 | 单独执行 |
| 排版 Agent | 长文格式规范化、目录索引、最终整合 | Phase 7 | 单独执行 |

---

## 完整流程

```
Phase 0: 启动（主编 Agent）
    ↓ 用户确认长文结构类型（罗胖60秒 / 罗辑思维长文 / 跨年演讲稿）
Phase 1: 选题与角度确认
    ↓ 用户确认选题、角度、读者、篇幅
Phase 2: 大纲设计（主编 Agent）
    ↓ 用户确认大纲（含 SCQA 变体 TQA/CAA/PEI）
Phase 3-4: 素材搜集与故事细节挖掘（调研 Agent × 2，并行）
    ↓ 案例/数据/金句汇总（必须含具体时间/地点/数字）
Phase 5: 撰写（写作 Agent × 2，并行）
    ↓ 每段/点/条完成、SCQA 标注、躬身入局框、启发框
Phase 6: 审校（编辑 Agent）
    ↓ 12 项 QC + 3 种结构 profile 通过（"大家"= 0）
Phase 7: 排版整合（排版 Agent）
    ↓ 格式规范化、目录索引
Phase 8: 定稿（主编 Agent）
```

## Phase 详细说明

### Phase 0: 启动与长文类型判断

**执行者**：主编 Agent

**任务**：
1. 判断长文类型（罗胖60秒 / 罗辑思维长文 / 跨年演讲稿）
2. 选定默认 SCQA 变体（全 skill 统一）：
   - 罗胖60秒 → **PEI**（现象-解释-启发）
   - 罗辑思维长文 → **TQA**（触发-问题-答案），备选 CAA
   - 跨年演讲稿 → **CAA**（具体-抽象-行动）
3. 创建项目目录结构
4. 初始化进度文件
5. 提示主编："本篇将围绕 12 大心法展开，请确保包含躬身入局/启发/故事细节，且金句、故事、比喻必须为当前主题现场原创。"

**输出**：
```
article-project/
├── .book/
│   ├── progress.json
│   ├── research/
│   ├── drafts/
│   └── reviews/
├── article.md
└── assets/
```

**交互**：向用户确认长文类型判断与 SCQA 变体

### Phase 1: 选题与角度确认

**交互模式**：渐进式配置菜单

```
请选择长文配置：

A. 结构类型
- A1 罗胖60秒（1 段，60-150 字，启发式输出）
- A2 罗辑思维长文（开头 + 3-5 主体 + 收束，2000-4000 字）
- A3 跨年演讲稿（开场 + 3-5 故事章节 + 收束，8000-15000 字）

B. 选题角度
- B1 商业评论（对热点事件、企业战略、行业现象的启发式评论）
- B2 历史启发（用历史故事给当代人启发）
- B3 创业故事（拆解一位企业家的躬身入局路径）
- B4 认知更新（介绍一个反常识的新认知）
- B5 跨年演讲（罗胖式跨年演讲稿：18 字心法 + 数字金句 + 故事细节）

C. 目标读者
- C1 大众读者
- C2 创业者
- C3 终身学习者
- C4 商业读者

D. 篇幅
- D1 极短（60-150 字）— 罗胖60秒
- D2 中（2000-4000 字）— 罗辑思维长文
- D3 长（8000-15000 字）— 跨年演讲稿

E. 必含心法（多选）
- E1 躬身入局
- E2 长期主义
- E3 启发式输出
- E4 一具体，就深刻
- E5 一行动，就创新
- E6 故事细节
- E7 金句主义
- E8 动词驱动
```

**确认节点**：用户必须确认配置（特别是 E 心法选项）

**注意**：罗振宇风格长文必含至少 3 个心法元素，跨年演讲稿需含 18 字心法

### Phase 2: 大纲设计

**执行者**：主编 Agent

**任务**：
1. 根据结构类型选择对应蓝图（book-blueprints.md）
2. 生成段/点/条的大纲
3. **显式标注 SCQA 节点位置**（T/C/Q/A 或 C/A/A 或 P/E/I）
4. **显式标注心法命中点**（每段/点对应哪几个心法）
5. **明确故事细节位**（含具体时间/地点/数字的占位）
6. 生成大纲预览

**输出**：
- `.book/outline.json`（使用 outline-schema.json 中的 article_type 字段）
- 大纲预览

**罗辑思维长文大纲示例（5 段 + TQA 变体）**：
```
引子：我是罗胖，今天想给你一个关于"长期主义"的启发。
       [T 触发：你可能正在为短期的挫败而焦虑？]
§01 第一段：长期主义不是熬时间，是在时间里做正确的事
       [Q 问题：为什么我们努力了却没看到结果？]
       [心法命中：长期主义 + 启发式输出]
       [故事细节占位：曾国藩"结硬寨打呆仗" / 跨大西洋电缆创业者 / 张廷玉悲剧（素材源可查的人物）]
§02 第二段：一具体，就深刻
       [A 答案（部分）：3 个具体案例]
       [心法命中：一具体就深刻 + 故事细节]
§03 第三段：一行动，就创新
       [A 答案（部分）：3 个行动案例]
       [心法命中：一行动就创新 + 躬身入局]
§04 第四段：我有一个启发
       [A 答案（完整）：把日复一日留给 AI，把日新月异交给人类]
       [心法命中：启发式输出 + 金句主义]
§05 收束：长期主义 + 躬身入局
       [心法命中：长期主义 + 躬身入局 + 谦卑自嘲]
```

**罗胖 60 秒大纲示例（1 段 + PEI 变体）**：
```
一段（60-150 字）：
  P 现象：今天我看到一条新闻……
  E 解释：这事儿让我想起……
  I 启发：我有一个启发……
  [心法命中：故事细节 + 启发式输出 + 金句主义]
```

**确认节点**：用户确认大纲与 SCQA 节点 + 心法命中

### Phase 3-4: 素材生成与事实核查（并行）

> **职责**：调研 Agent 不是"收集代表作现成素材来照搬"，而是"**为当前主题现场生成贴合的新金句/新案例/新比喻**"。代表作素材只作为风格参照。

**调研 Agent #1** - 为当前主题生成故事与案例：
- 根据本篇主题，**为每个核心观点构造一个贴合的新故事**（不要默认回到曾国藩/张廷玉）
- 用故事生成公式：`[什么人]+[遇到什么]+[关键决策]+[具体细节]+[结果]`
- 故事人物可以是真实人物（事迹须可查）或典型人物（"做外贸的老王"）
- 参考罗振宇风格的"怎么讲故事"，但不照搬其案例
- 输出到 `.book/research/cases.md`

**调研 Agent #2** - 为当前主题生成金句与比喻：
- 根据本篇主题，**用 4 步法现场提炼 5-8 句原创金句**（先写平淡版→压缩→套句式公式→打磨）
- 用 7 种句式公式（对仗/重定义/反常识/一X就Y/工具/二元/数字）套当前主题内容
- 为核心概念**现场造 1-2 个原创比喻**（[抽象] 就像 [具象]）
- 参考素材源可查的数字（3652 条/11 场/523 个词条/1000 天/18 字心法）作风格范例，不照搬原句
- 输出到 `.book/research/jinju.md` 和 `.book/research/data.md`

**事实核查要求**：
- 引用真实人物的具体事迹/语录/数字，必须有据可查；不确定就模糊处理（"很多年前""有一次"）
- 不要编造名人具体语录、具体日期、具体数字
- 商业黑话检测：避免"赋能""抓手""底层逻辑""打通""闭环"
- **原创性检查**：生成的金句/故事不得与代表作原句雷同，连续多篇文章之间不得重复用同一批案例

**输出**：
- `.book/research/cases.md`（为本次主题生成的案例库）
- `.book/research/data.md`（数据与数字金句）
- `.book/research/jinju.md`（为本次主题原创的金句素材）
- `.book/research/facts-check.md`（事实核查报告）

### Phase 5: 长文撰写

**执行者**：写作 Agent（最多 2 个并行）

**每段/点/条流程**：
1. 根据结构类型选择对应模板（chapter-templates.md）
2. 撰写内容，遵循 style-dna.md 12 大心法（金句/故事/比喻现场原创）
3. 显式标注 SCQA 节点（用 `**T 触发**` `**Q 问题**` `**A 答案**` 或 `**C 具体**` `**A 抽象**` `**A 行动**` 或 `**P 现象**` `**E 解释**` `**I 启发**` 标记）
4. **至少使用 1 个躬身入局框**（callout-patterns.md 7 种格式之一）
5. **至少使用 1 个故事细节框**（含具体时间/地点/数字）
6. **至少使用 1 个启发框**（"我有一个启发……"）
7. **至少使用 1 个金句框**（对仗式 / 动词式 / 解构式 / 反差式 / 数字式 / 递进式 / 分配式）
8. 执行 QC 自检（12 项）
9. 保存草稿
10. 等待用户确认

**SCQA 标注示例（TQA）**：
```markdown
**T 触发**：你可能正在为短期的挫败而焦虑。
[正文展开]

> **躬身入局**：做事的人不是置身事外指点江山，而是躬身入局，把自己变成解决问题的关键变量。

**Q 问题**：为什么我们努力了，却没看到结果？

> **金句**：长期主义不是熬时间，是在时间里做正确的事。

**A 答案**：把日复一日留给 AI，把日新月异交给人类。

> **故事细节**：三年前（约 1000 天前），这位主理人放弃一线城市的互联网工作，来到三亚经营一家濒临倒闭的民宿。
```

**罗胖 60 秒特别说明**（极简流程）：
```markdown
**P 现象**：今天我看到一条新闻，[具体数字]。

> **故事细节**：[含具体时间/地点/数字的一句话]

**E 解释**：这事儿让我想起 [曾国藩 / 王阳明 / 历史故事]。

**I 启发**：我有一个启发，[金句]。
```

**确认节点**：每段/点/条完成需要用户确认

**输出**：
- `.book/drafts/article-v1.md`

---

### Phase 6: 编辑审校

**执行者**：编辑 Agent

**任务**：
1. 执行每段/点/条 12 项 QC（结构 4 + 风格 5 + 内容 3）
2. 执行全文 10 项 QC
3. 根据结构类型加载对应 profile（罗胖60秒 / 罗辑思维长文 / 跨年演讲稿）
4. SCQA 完整性检查：T/Q/A 或 C/A/A 或 P/E/I 节点是否齐全且顺序正确
5. **躬身入局检查**：每篇 ≥ 1 个躬身入局框（罗胖标志性）
6. **启发框检查**：每篇 ≥ 1 个"我有一个启发……"或"启示"
7. **故事细节检查**：每篇 ≥ 1 个含具体时间/地点/数字的故事
8. **数字金句检查**（跨年演讲稿）：≥ 2 个数字金句（素材源可查：3652 条 / 11 场 / 523 个词条 / 1000 天 / 18 字心法级别）
9. **禁用词零容忍检查**：
   - 「大家」= 0
   - 「赋能」「抓手」「底层逻辑」「打通」「闭环」= 0
   - 「我们」出现频率 < 每千字 5 次（罗胖更倾向"我"+"你"）
10. 生成审校报告

**确认节点**：用户确认是否执行修复

**输出**：
- `.book/reviews/edit-notes.md`
- `.book/reviews/quality-report.md`

---

### Phase 7: 排版整合

**执行者**：排版 Agent

**任务**：
1. 格式规范化（统一 H 层级、callout 格式、表格语法）
2. 整理长文结构（添加必要的目录索引、章节衔接）
3. 合并所有段落/点/条
4. **添加罗振宇风格标识**（"我是罗胖"开篇、18 字心法版块、数字金句角标）
5. 准备最终交付的 Markdown 文件

**输出**：
- `.book/final/article-final.md`

**确认节点**：用户验收长文 Markdown

---

### Phase 8: 精校定稿

**执行者**：主编 Agent

**任务**：
1. 最终质量检查（12 大心法对照 + **原创性检查**：金句/故事是否为当前主题现场生成，未照搬代表作）
2. 打包交付物
3. 可选清理过程文件

**最终交付**：
```
article-project/
├── article-final.md
├── .book/
└── README.md
```

## Agent 通信机制

1. **状态共享**：通过 `.book/progress.json` 共享进度
2. **文件传递**：通过 `.book/research/` 和 `.book/drafts/` 传递中间产物
3. **用户确认**：关键节点（Phase 1 配置、Phase 2 大纲、Phase 5 每段/点/条、Phase 7 排版）必须等待用户确认

## 12 大心法在协作流中的体现

| 心法 | 体现位置 |
|------|----------|
| **躬身入局** | Phase 1 必选 E1；Phase 5 至少 1 个躬身入局框 |
| **长期主义** | Phase 1 可选 E2；Phase 5 长期主义框（如主题相关）|
| **启发式输出** | Phase 1 必选 E3；Phase 5 必含"我有一个启发"框 |
| **一具体，就深刻** | Phase 3-4 调研必含具体细节；Phase 5 故事细节框 |
| **一行动，就创新** | Phase 5 行动召唤段 |
| **一困惑，就出门** | Phase 5 至少 1 次"出门/走访"场景 |
| **故事细节** | Phase 3-4 为本主题生成新案例；Phase 5 故事框（连续多篇不重复）|
| **金句主义** | Phase 3-4 为本主题现场原创金句；Phase 5 ≥ 1 个金句框 |
| **打比方** | Phase 3-4 为本主题造原创比喻；Phase 5 ≥ 1 个比方框 |
| **举例降认知** | Phase 3-4 构造小张式具体例子；Phase 5 ≥ 1 个举例框 |
| **动词驱动** | Phase 5 全文动词占比 ≥ 1/3 |
| **谦卑自嘲** | Phase 5 至少 1 个自嘲框（开篇最佳）|

## 错误处理

| 错误场景 | 处理方式 |
|---------|----------|
| 故事细节缺乏具体时间/地点/数字 | 标注「待补细节」，回写到 Phase 3-4 重新调研 |
| 数据来源不可靠 | 标记 warning，不在金句中使用 |
| 用户拒绝确认 | 收集反馈后重新执行 |
| SCQA 节点缺失 | 编辑 Agent 必须要求回写到 Phase 2 重做 |
| 「大家」出现 ≥ 1 次 | 编辑 Agent 必须强制替换为「你」或具体人名 |
| 躬身入局框缺失 | 编辑 Agent 必须回写到 Phase 5 补写 |
| 启发框缺失 | 编辑 Agent 必须回写到 Phase 5 补"我有一个启发" |
| 数字金句缺失（跨年演讲稿）| 编辑 Agent 必须回写到 Phase 5 补充素材源可查的数字（3652 条 / 1000 天 / 18 字心法级别）|
| 句长 > 40 字连续 5 句 | 触发推敲流程，要求拆句 |
| 「我们」频次 > 5/千字 | 触发推敲流程，要求改为"我"+"你" |

## 罗振宇 vs 刘润 协作差异

| 维度 | 罗振宇（luozhenyu）| 刘润（liurun）|
|------|---------------------|----------------|
| 必含元素 | 躬身入局 + 启发 + 数字金句 | 同理心 + 自污 + 商业案例 |
| 禁用词严度 | 「大家」「我们」更严 | 「大家」零容忍 |
| 故事要求 | 必须含具体时间/地点/数字 | 含具体场景即可 |
| SCQA 变体 | TQA / CAA / PEI | ASC / QSCA / CSA |
| 心法数量 | 12 大心法 | 8 大心法 |
| 收束方式 | 启发式（"我有一个启发"）| 金句升华 |
| 篇幅差异 | 跨年稿可达 15000 字 | 商业长文 1500-5000 字 |
