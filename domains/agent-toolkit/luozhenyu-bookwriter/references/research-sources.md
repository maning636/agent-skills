> 罗振宇的内容是**风格范例库**，不是抄写本。本文件列出的金句、人物、句式都是**范例**，学的是"罗振宇怎么造金句、怎么用人物、怎么搭结构"。
> 每篇新文章都要为当前主题**现场原创**金句、**重新寻找/构造**贴合的故事，不得直接套用本文件列出的代表作原句。
> 调研阶段的工作重点是：①确认事实（谁说了什么、哪年哪场）②**为新主题现场生成**贴合的新金句/新案例/新比喻。

## 零、素材生成方法（写作前必读）

### 金句现场提炼 4 步法

```
1. 先写平淡版：把你想说的道理，用大白话写出来
2. 压缩到 15 字内
3. 加对仗/类比/反问（套 7 种句式公式之一）
4. 打磨到朗朗上口（节奏感，反复念）
```

**示范**（理解方法，勿照搬）：
- 平淡版："做事比空想重要" → 压缩："做事比想重要" → 套"一X就Y"："一做事，就踏实"
- 平淡版："习惯很难改" → 压缩："旧习惯顽固" → 套重定义式："习惯不是记性差，是河道深"

### 为新主题生成故事的公式

```
[什么人] + [遇到什么处境] + [做出什么关键决策] + [具体细节] + [结果/启示]
```
不要每次都用曾国藩/张廷玉/跨大西洋电缆——为每个新主题找一个更贴切的人物。

### 为新主题生成比喻的思路

```
先问：这个抽象概念，在生活中像什么具体事物？
再问：那个事物的什么特点，恰好能解释这个概念？
```

## 四、风格 DNA 提取方法

### 4.1 提取流程

1. **精读阶段**：
   - 选 markdown 中 5-10 篇罗胖 60 秒（向内问两个问题 / 劝酒 / 考场逻辑 / 拆目标 / 长期主义）
   - 选 3-5 篇《罗辑思维》长文（成大事者不纠结 / 怎么当个明白人 / 怎么挣钱 / 太平洋）
   - 选 3 场跨年演讲（2019 / 2024 / 2026）
   - 选 1 本书（《启发》或《成大事者不纠结》）

2. **标注阶段**：
   - 标注所有"罗胖式"开头（"我是罗胖" / "你可能正在" / "今天我看到"）
   - 标注所有金句（对仗 / 数字 / 重定义 / 反常识 / 工具）
   - 标注所有故事细节（曾国藩 / 张廷玉 / 跨大西洋电缆 / 3652 条 / 1000 天 / 18 字）
   - 标注所有 SCQA 节点
   - 标注所有躬身入局信号
   - 标注所有"启发"信号

3. **量化阶段**：
   - "我" 频次
   - "你" 频次
   - "大家" 次数（应 = 0）
   - "我们" 频次
   - 金句密度
   - 句长
   - 故事/细节数量

4. **总结阶段**：
   - 提炼风格指纹
   - 提取禁用词清单
   - 总结 SCQA 变体偏好

### 4.2 关键判断标准

- 这段话**罗胖会说吗**？— 自检最高标准
- 是否有具体时间/地点/人物/数字？— 故事细节硬指标
- 是否有"我有一个启发"？— 启发框硬指标
- 是否用了"大家"？— 零容忍
- 句长是否 ≤ 40 字？— 节奏硬指标
- **金句是否为当前主题现场原创？** — **多样性硬指标**（不得直接套用代表作原句）
- **人物/事件是否真实可查？** — 真实性硬指标（不确定就模糊处理或用典型人物，不编造）
