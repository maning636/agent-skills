## 六、可查的"罗振宇标志性句式"（基于真实代表作）

### 6.1 "放弃A，转而B"对仗式
**出处**：《和你赛跑的不是人》
> "放弃追求地位，转而追求联系；
> 放弃追求效率，转而追求趣味。"

**模板**：
```
放弃[追求X]，[转而追求Y]。
放弃[拥有X]，[转而拥抱Y]。
```

### 6.2 "X不是A，是B"重定义式
**出处**：《你因挣钱而伟大》《大英帝国》
> "挣钱不是俗气，是体面。"
> "不控制，反而是控制。"

> 注："长期主义 ≠ 熬时间，是在时间里做正确的事"是 skill 对《长期主义还活着》的释义性表述，非 markdown 原句，使用时勿标注为"罗振宇原话"。

**模板**：
```
[X] 不是 [A]，[是 B]。
[X] ≠ [A]，是 B。
```

### 6.3 "X是X，Y是Y"解构式
**出处**：罗胖 60 秒的二元解构
> "考场逻辑是考场逻辑，社会逻辑是社会逻辑。"
> "存量是存量，增量是增量。"

**模板**：
```
[X] 是 [X]，[Y] 是 [Y]。
[看起来的X] ≠ [实际的X]。
```

### 6.4 "看一个人X，看他Y"观察式
**出处**：《看一个人工作能力，看他会不会拆目标》
> "看一个人工作能力，看他会不会拆目标。"

**模板**：
```
看一个人[属性]，[看他/她][具体观察点]。
判断[一个事]，[看他/它][关键观察点]。
```

### 6.5 "向内问X个问题"自问式
**出处**：《一件事靠不靠谱，向内问两个问题》
> "一件事靠不靠谱，向内问两个问题。
> 第一，如果做了，会不会后悔？
> 第二，如果没做，会不会不甘心？"

**模板**：
```
[X 这件事]，[向内问Y个问题]。
第一，[问题1]？
第二，[问题2]？
```

### 6.6 "X vs Y"二元解构式（罗胖 60 秒高频）
**出处**：
- 考场逻辑 vs 社会逻辑
- 评价者 vs 合作者（skill 中扩展）
- 一次性博弈 vs 多次博弈
- 存量 vs 增量

**模板**：
```
[A] vs [B]：[A 的局限] vs [B 的真相]
```

### 6.7 "A、B、C、D"四字对仗动作序列
**出处**：《微革命：转身、立定、呻吟、躺下》
> "转身、立定、呻吟、躺下"

**模板**：
```
[动作1]、[动作2]、[动作3]、[动作4]
```

### 6.8 "一X，就Y"对仗式
**出处**：2024 跨年演讲 18 字心法
> "一具体，就深刻。"
> "一行动，就创新。"

**模板**：
```
一[动词/名词]，[就][形容词/动词]。
```

### 8.2 素材生成指南（为每个新主题现场造内容）

**原则**：代表作金句/人物是**句式范例和风格参照**，学"怎么造"，不抄"造了什么"。

#### 为新主题生成金句（4 步法）

```
1. 先写平淡版：把道理用大白话说出来
2. 压缩到 15 字内
3. 套一个句式公式（对仗/重定义/反常识/一X就Y/工具/二元/数字）
4. 打磨到朗朗上口（反复念，调字序换动词）
```

**示范**（理解方法，勿照搬）：
- 主题"坚持" → "不是因为看见了希望才坚持，是坚持了才看见希望。"
- 主题"简单" → "把复杂的事做简单，比把简单的事做复杂，难一万倍。"

#### 为新主题生成故事

```
[什么人] + [遇到什么具体处境] + [做出什么关键决策] + [具体细节] + [结果/启示]
```
- 不要每次都用曾国藩/张廷玉/跨大西洋电缆
- 为"专注"找匠人故事，为"转型"找二次创业者故事，为"教育"找师生故事

#### 为新主题生成比喻

```
[抽象概念] 就像 [生活中具体的事物] → 解释这个事物的哪个机制恰好说明该概念
```
- 写"习惯" → "习惯就像水流，每次重复都在加深河道。"
- 写"认知" → "认知就像一副眼镜，它让你看见世界，也限制你看见的世界。"
