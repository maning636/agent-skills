## P0 · 封面

- **标题**：AI 工具选哪个不踩雷
- **副标**：3 大类 9 款 · 2026 实测
- **副副标**：手绘叙事风 PPT 示范
- **章节类型**：封面
- **核心主张**：3 类工具 × 3 款推荐 = 9 个不踩雷的选择
- **认知锚点**：「3 类 × 3 款矩阵」—— 一眼分类 + 推荐
- **关键要点**：
  - 类 1：通用对话（ChatGPT / Claude / Gemini）
  - 类 2：代码生成（Cursor / Copilot / Windsurf）
  - 类 3：研究检索（Perplexity / 秘塔 / 书生）
  - 每类 3 款 = 9 选 1 矩阵
- **数据 / 数字**：3 类 / 9 款 / 0 坑
- **金句**：工具不是越多越好，是越准越好。

## P1 · 钩子 · 大家都在用 AI，但选错浪费时间

- **章节类型**：钩子
- **核心主张**：选错 AI 工具 = 浪费 30% 时间
- **认知锚点**：「选错工具的 3 大症状」—— 用错类、用贵款、用错场景
- **关键要点**：
  - 症状 1：用 ChatGPT 写代码 = 通用对话模型做专事
  - 症状 2：买 Copilot 套餐但不用 VSCode = 浪费
  - 症状 3：用 Perplexity 写公众号 = 检索做创作
- **数据 / 数字**：3 症状 / 30% 时间浪费
- **金句**：选错 AI 工具 = 给自己配 1 个不对的同事。

## P2 · 总纲 · 3 大类 9 款

- **章节类型**：总纲
- **核心主张**：3 大类覆盖 90% AI 工具使用场景
- **认知锚点**：「3 类 9 款矩阵」—— 3x3 网格
- **关键要点**：
  - 通用对话：1 人对话 / 日常问题
  - 代码生成：IDE 内 / 代码补全
  - 研究检索：实时信息 / 引用来源
- **数据 / 数字**：3 类 / 9 款 / 3x3 网格
- **金句**：先分类，再选款。

## P3 · 核心解法 · 每类 3 款推荐

- **章节类型**：核心解法
- **核心主张**：每类 3 款 = 3 个不同价位的选择
- **认知锚点**：「3 类 3 款 = 9 选 1 矩阵」—— 价格梯度
- **关键要点**：
  - 通用对话：ChatGPT Plus（$20） / Claude Pro（$20） / Gemini Advanced（$20）
  - 代码生成：Cursor Pro（$20） / Copilot（$10） / Windsurf（$15）
  - 研究检索：Perplexity Pro（$20） / 秘塔（¥0-99） / 书生（¥0-99）
- **数据 / 数字**：3 类 × 3 款 = 9 选 / 0 选错
- **金句**：每类选 1 款 = 3 个工具 = 60 美元/月 = 顶配。

## P4 · 案例 · 3 个真实用户的选择

- **章节类型**：案例
- **核心主张**：3 类用户 = 3 种最优搭配
- **认知锚点**：「3 用户 × 3 工具矩阵」—— 实战选款
- **关键要点**：
  - 用户 A（产品经理）：ChatGPT Plus + Cursor + Perplexity
  - 用户 B（开发者）：Claude Pro + Cursor + 秘塔
  - 用户 C（研究员）：Gemini Advanced + Copilot + 书生
- **数据 / 数字**：3 用户 / 3 搭配 / 60 美元/月
- **金句**：3 个用户 = 3 种最佳搭配 = 选款不是单选。

## P5 · 收束 · 1 步开始

- **章节类型**：收束
- **核心主张**：先选 1 类 1 款，3 个月再加
- **认知锚点**：「先选 1 款」—— 30 天落地路径
- **关键要点**：
  - 第 1 个月：选 1 类 1 款，用 30 天
  - 第 2 个月：加第 2 类 1 款
  - 第 3 个月：凑齐 3 类 3 款
- **数据 / 数字**：3 个月 / 3 类 / 60 美元/月
- **金句**：1 款 = 立刻开始 = 30 天见效。
