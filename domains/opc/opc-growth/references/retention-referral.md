# 复购与裂变机制

用于把一次性客户转化为长期收入和转介绍来源。核心原则：先交付超预期价值，再设计激励。

## 复购策略

| 方法 | 具体操作 | 适用场景 |
|------|----------|----------|
| 订阅制转化 | 单次项目后转月度服务 | 持续性需求，如内容、数据、客服 |
| 会员体系 | VIP等级、优先响应、专属模板 | 高频消费客户 |
| 自动续费 | 到期前提醒，可取消 | SaaS、工具、知识库 |
| 结果复盘 | 交付后给改进建议 | 咨询、运营、增长服务 |
| 升级销售 | 推荐更高级服务 | 客户满意且有更大目标 |

订阅制前提：交付质量稳定，返工率可控，客户每月都有明确获得感。

## 裂变公式

```
裂变效果 = 激励力度 × 分享便利性 × 信任度
```

| 机制 | 激励设计 | 适用场景 |
|------|----------|----------|
| 推荐返现 | 推荐成交后返固定金额或比例 | 高客单服务 |
| 邀请有礼 | 双方都获得模板、折扣或权益 | 低客单产品 |
| 分销佣金 | 持续返佣 | 课程、工具、模板 |
| 案例共创 | 客户获得曝光，你获得背书 | B端服务 |
| 联名推荐 | 与互补服务商互推 | 非竞品 OPC |

## 客户维护节奏

| 时间点 | 动作 |
|--------|------|
| 交付后3-7天 | 满意度调查、问题修复 |
| 交付后14天 | 发送相关行业干货或使用建议 |
| 交付后30天 | 发送续费、升级或复购方案 |
| 行业大事件 | 发送解读报告，建立专家形象 |
| 客户重要节点 | 祝福、专属优惠、案例复盘 |

## 指标

| 指标 | 健康值 |
|------|--------|
| 服务类复购率 | >30%，成熟后>50% |
| 产品类续费率 | >60% |
| 推荐率 | >20% |
| NPS | >50 |
| 单一客户收入占比 | <30% |

## 输出建议

当用户说“客户不回头”时，先判断是需求不持续、交付不稳定，还是缺少复购触发；不要直接设计裂变活动。
