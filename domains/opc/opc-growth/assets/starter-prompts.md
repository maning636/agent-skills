# 新手先用的 5 个 Prompt

这些 prompt 用于从 0 到首单的最小增长闭环。先用这 5 个跑通流程，再去使用完整提示词库。

## 1. 访谈问题生成

```
你是一位一人公司创业顾问。请帮我为以下目标用户设计10个访谈问题：

目标用户：____
我想验证的问题：____
我计划提供的AI服务：____

要求：
1. 只问过去真实行为，不问“你会不会买”这种假设题。
2. 问题要能发现痛点频率、当前替代方案、付费能力和决策流程。
3. 最后给我一个访谈记录表格。
```

## 2. 小红书/公众号选题生成

```
你是一位内容获客顾问。请基于以下信息生成20个内容选题：

目标用户：____
用户痛点：____
我的服务：____
平台：小红书 / 公众号 / 即刻 / 其他：____

要求：
1. 每个选题必须对应一个具体痛点。
2. 标出适合的内容形式：案例、避坑、清单、教程、对比。
3. 给每个选题一个转化CTA。
4. 优先生成能带来咨询的选题，而不是泛流量选题。
```

## 3. 私信破冰话术

```
你是一位B端销售顾问。请帮我写5条私信破冰话术：

目标客户：____
我观察到的问题：____
我能提供的结果：____
我希望对方做的下一步：____

要求：
1. 不要硬广，不要夸大承诺。
2. 每条不超过120字。
3. 先表达观察，再给一个低压力下一步。
4. 给出适合熟人、半熟人、陌生人的不同版本。
```

## 4. 需求诊断表

```
你是一位AI服务交付顾问。请为我的服务设计一份3分钟需求诊断表：

服务类型：____
目标客户：____
典型痛点：____
交付结果：____

要求：
1. 问题不超过10个。
2. 覆盖行业、规模、当前做法、痛点损失、期望结果、预算、时间、决策人。
3. 输出可直接复制到飞书表单/问卷星的格式。
4. 最后给我一套根据答案判断客户意向等级的规则。
```

## 5. 三档报价方案

```
你是一位一人公司定价顾问。请为我的AI服务设计三档报价：

服务内容：____
目标客户：____
交付成本：____
客户痛点价值：____
我的经验/案例：____

要求：
1. 给出试点版、标准版、深度版三档。
2. 每档写清价格、交付物、不包含内容、交付周期、适合客户。
3. 标准版作为主推方案。
4. 给出3个常见异议和回应话术。
```
