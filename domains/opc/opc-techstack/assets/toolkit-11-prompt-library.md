### 1.1 小红书爆款文案生成

**场景说明**：将产品卖点或知识干货转化为小红书风格笔记，包含标题、正文、标签和排版建议。

**提示词模板**：

```
你是一位小红书资深内容操盘手，擅长写爆款笔记。

请根据以下信息，生成一篇小红书笔记：
- 主题/产品：[填入你的产品或内容主题]
- 核心卖点：[填入 1-3 个核心卖点]
- 目标人群：[填入目标用户，如"25-35 岁职场女性"]
- 笔记类型：[知识干货/好物分享/避坑指南/经验总结，选一个]
- 期望字数：[300 字 / 500 字 / 800 字]

要求：
1. 标题：写 3 个备选，要求包含数字、情绪词或悬念
2. 正文：用 emoji 分段，口语化表达，避免广告感
3. 结尾：引导点赞收藏或评论区互动
4. 标签：提供 8-12 个相关话题标签
5. 排版建议：说明哪些关键词需要加粗、换行位置
```

**使用建议**：如果不确定主题，可以先让 AI 帮你脑暴 10 个选题，再选其一深入。

**预期输出示例**：

```
📌 标题备选：
1. 闷声发财｜我靠这个副业月入 3W+（附方法）
2. 千万别再做自媒体了！除非你看过这篇
3. 30 岁裸辞后，我发现了 5 个搞钱信息差

正文：
姐妹们！今天分享一个我亲测有效的...
...

🏷️ 标签：
#副业 #自媒体 #搞钱 #自由职业 #一人公司
```

### 1.2 公众号深度长文撰写

**场景说明**：将碎片化思考或知识要点扩展成结构完整、论证充分的公众号长文。

**提示词模板**：

```
你是一位擅长写深度长文的公众号主笔，文风理性克制、逻辑清晰。

请基于以下素材，撰写一篇公众号长文：
- 文章主题：[填入主题]
- 核心观点：[填入你的核心论点，一句话]
- 已有素材：[填入你已整理的要点、数据、案例，可用 bullet points]
- 目标字数：[2000 字 / 3000 字 / 5000 字]
- 目标读者：[填入读者画像]

要求：
1. 开头用 "钩子" 引入——一个故事、一个数据反差或一个反常识观点
2. 正文采用 "总-分-总" 或 "问题-分析-方案" 结构，每部分有小标题
3. 至少引用 2 个具体案例或数据支撑论点
4. 金句：在文中自然嵌入 3-5 个适合被摘抄传播的金句
5. 结尾：总结核心观点 + 引导转发/关注/评论
6. 提供 3 个备选标题，要求涵盖 "痛点型""悬念型""数字型"
```

**使用建议**：如果素材不足，可以先执行一轮 "素材扩展" 提示词，让 AI 帮你补充案例和数据。

**预期输出示例**：

```
标题备选：
1. 为什么你越努力，越赚不到钱？（深度）
2. 月入 10 万的人，都在做同一件事
3. 我观察了 100 个自由职业者，发现 3 个残酷真相

正文结构：
一、现象：大家都想搞副业，为什么只有少数人能成？
二、误区：这 3 个错误让 90% 的人半途而废
三、方法：从零到一的正确路径
四、案例：3 个真实转型故事
五、总结：长期主义才是答案
```

### 1.3 短视频脚本生成

**场景说明**：为抖音/视频号/B站生成包含画面描述、台词和时长的完整脚本。

**提示词模板**：

```
你是一位短视频脚本导演，擅长写高完播率的口播和 vlog 脚本。

请根据以下信息生成脚本：
- 平台：[抖音 / 视频号 / B站 / 小红书视频]
- 视频主题：[填入主题]
- 时长：[30 秒 / 60 秒 / 3 分钟]
- 风格：[知识科普 / 情绪共鸣 / 产品种草 / 故事叙事]
- 出镜人设定：[专家人设 / 朋友推荐 / 亲历者故事]

要求：
1. 以表格形式输出，列包含：时间轴、画面描述、台词/字幕、音效/特效提示
2. 前 3 秒必须有 "黄金钩子"，能留住观众
3. 中间设置 1 个 "互动点"（提问或引导评论）
4. 结尾有明确的 CTA（关注/点赞/进粉丝群/点击链接）
5. 标注哪些台词需要重音、停顿或情绪变化
```

**使用建议**：同一主题可要求生成 "口播版" 和 "vlog 版" 两个版本，测试哪种完播率更高。

**预期输出示例**：

```
| 时间 | 画面 | 台词/字幕 | 备注 |
|------|------|-----------|------|
| 0-3s | 黑屏白字，大字标题 | "99% 的人不知道，AI 已经能替你..." | 重音在"99%" |
| 3-15s | 博主出镜，表情惊讶 | "我上周用 AI 写了一份商业计划书，投资人居然..." | 停顿在"居然"后 |
| ... | ... | ... | ... |
```

### 1.4 邮件营销文案

**场景说明**：撰写高打开率、高点击率的营销邮件，适用于产品发布、课程促销、活动邀请等。

**提示词模板**：

```
你是一位邮件营销专家，平均邮件打开率 35%+，点击率 8%+。

请撰写一封营销邮件：
- 邮件类型：[新品发布 / 限时促销 / 课程发售 / 活动邀请 / 用户召回]
- 产品/服务名称：[填入名称]
- 核心卖点：[填入 1-2 个最吸引人的卖点]
- 目标受众：[填入受众画像]
- 价格/优惠：[填入价格信息，如"原价 999，早鸟价 399"]
- 行动目标：[点击购买 / 预约直播 / 回复邮件 / 转发给同事]
- 发送场景：[冷启动首封 / 老用户复购 / 购物车挽回]

要求：
1. 主题行：提供 5 个备选，要求引发好奇心或紧迫感，避免垃圾词
2. 正文：
   - 第一段：共情读者痛点（2-3 句话）
   - 第二段：介绍解决方案/产品，聚焦一个核心利益点
   - 第三段：社会证明（用户评价/数据/案例）
   - 第四段：限时优惠或稀缺性说明
   - CTA 按钮文案：提供 3 个备选
3. 结尾 P.S.：写一个让人忍不住回看的附言
4. 整体语气：[亲切朋友感 / 专业权威感 / 紧迫感]
```

**使用建议**：发送前用 A/B 测试不同主题行，优先测试带 personalization（如用户名）的版本。

**预期输出示例**：

```
主题行备选：
1. [姓名]，你上次问的终于有货了
2. 仅限今晚｜这个工具让我每周省下 10 小时
3. 不是每个人都适合这个课——但也许适合你
4. 我们做了一个艰难的决定（关于定价）
5. 打开这封邮件的人，3 天后都反馈了同一件事

正文：
[姓名]，你好。

我知道你每天最头疼的事是...
...

CTA 按钮备选：
- 立即锁定早鸟价 →
- 花 2 分钟看看详情 →
- 是的，我想节省 10 小时/周 →

P.S. 前 50 名下单赠送《XX 手册》，目前还剩 12 个名额。
```

### 1.5 产品落地页文案

**场景说明**：为独立产品、课程或服务生成高转化率的 Landing Page 文案。

**提示词模板**：

```
你是一位转化率优化（CRO）专家，擅长写高转化的产品落地页文案。

请为以下产品撰写落地页文案：
- 产品名称：[填入名称]
- 产品类型：[SaaS 工具 / 在线课程 / 咨询服务 / 实体产品 / 电子书]
- 一句话介绍：[填入产品的一句话描述]
- 核心功能/模块：[列出 3-5 个核心功能]
- 目标用户：[填入用户画像]
- 用户痛点：[填入 2-3 个主要痛点]
- 价格：[填入价格]
- 独特卖点（USP）：[填入你与竞品最大的不同]
- 社会证明：[填入已有用户数、评分、知名客户等]

要求按以下模块输出：
1. Hero Section（首屏）：主标题（10 字内）+ 副标题（20 字内）+ CTA 按钮文案
2. 痛点共鸣区：3 个用户痛点，每个痛点配一句共情文案
3. 解决方案区：产品如何解决上述痛点，用"功能 → 好处 → 结果"三段式
4. 功能特性区：3-5 个核心功能，每个配图标描述 + 一句话价值说明
5. 社会证明区：用户评价模板（提供 3 条不同角度的评价文案）
6. 定价区：价格展示 + 对比锚定 + 风险逆转（退款保证）
7. FAQ 区：5 个常见问题的问答文案
8. 最终 CTA 区：紧迫感文案 + 最终行动按钮
```

**使用建议**：落地页的首屏文案决定 80% 的留存。主标题如果 10 秒内不能让访客理解价值，就需要重写。

**预期输出示例**：

```
Hero Section：
- 主标题：AI 帮你写，3 倍速出稿
- 副标题：专为自媒体人设计的 AI 内容助手，从选题到发布只需 30 分钟
- CTA：免费试用 7 天，无需信用卡

痛点共鸣区：
"每天花 4 小时写稿，产出却只有 1 篇？"
"选题枯竭，发了 100 篇还是没人看？"
"想请写手，但预算不够、质量不稳定？"
```

### 1.6 社交媒体多平台适配

**场景说明**：将同一内容改写成适合不同平台的版本，最大化内容复用效率。

**提示词模板**：

```
你是一位全平台社交媒体运营专家，深谙各平台调性差异。

请将以下内容改写为 4 个平台的版本：
- 原始内容：[填入你的原文，可以是文章、观点、产品信息等]
- 原始字数：[填入字数]

平台要求：
1. 小红书版：
   - 风格：亲切、emoji 丰富、个人经验分享感
   - 格式：标题 + 正文 + 标签
   - 字数：300-500 字

2. 微博版：
   - 风格：犀利、热点感、可转发性
   - 格式：短文案 + 话题标签 + 可配图说明
   - 字数：140-300 字

3. 即刻版：
   - 风格：圈内人交流感、轻松、有梗
   - 格式：短段落 + 标签
   - 字数：100-200 字

4. 推特/X 版：
   - 风格：简洁有力、数据支撑、观点鲜明
   - 格式：单条推文（英文优先，或中英双语）
   - 字数：280 字符内（英文版）

额外要求：
- 保持核心信息一致
- 每个版本都适配平台用户阅读习惯
- 提供各版本的最佳发布时间建议
```

**使用建议**：原始内容建议控制在 1000 字以内，信息越聚焦，多平台改写效果越好。

**预期输出示例**：

```
小红书版：
🌟 标题：我用 AI 做了 3 个月自媒体，发现了 5 个真相...
正文：姐妹们！今天说点大实话...

2. ...
#AI改变工作方式 #自媒体干货

即刻版：
试了一圈 AI 写作工具，有些确实能让内容产出翻倍，但有些纯纯智商税...
#AI #自媒体

推特版：
I spent 90 days building a solo media business with AI.

### 2.1 竞品分析报告生成

**场景说明**：快速生成一份结构化的竞品分析报告，用于产品定位或投资决策。

**提示词模板**：

```
你是一位资深战略分析师，擅长竞品分析和市场洞察。

请对以下竞品进行分析：
- 我的产品/服务：[填入你的产品名称和定位]
- 竞品清单：[填入 2-5 个竞品名称]
- 分析目的：[产品定位参考 / 寻找差异化 / 投资决策 / 市场进入策略]
- 关注维度（可多选）：[功能对比 / 定价策略 / 用户口碑 / 营销渠道 / 技术架构 / 团队背景]

请按以下结构输出报告：
1. 执行摘要：3 段话概括核心发现
2. 竞品概览表：包含竞品名称、成立时间、融资情况、核心用户群、定价区间
3. 逐竞品深度分析（每个竞品）：
   - 产品定位与核心功能
   - 优势（至少 3 点）
   - 劣势/用户吐槽（至少 3 点，基于公开评论）
   - 营销策略和获客渠道
   - 最新动态（近 6 个月产品/融资/合作动态）
4. 功能对比矩阵：用表格对比各竞品在关键功能上的支持情况
5. 差异化机会分析：
   - 竞品未覆盖的痛点
   - 我可以切入的差异化定位
   - 建议的产品/定价/营销策略
6. 风险提示：分析中可能存在的信息盲区或假设

要求：所有分析基于公开可获取的信息，不确定的地方标注"待验证"。
```

**使用建议**：如果 AI 知识截止日期较早，可以先让 AI 列出信息搜集清单，你再人工补充最新动态。

**预期输出示例**：

```
竞品概览表：
| 竞品 | 成立 | 融资 | 核心用户 | 定价 |
|------|------|------|----------|------|
| A | 2019 | B轮 | 中小企业 | 99/月 |
| B | 2021 | A轮 | 个人创作者 | 免费+Pro 199/年 |

差异化机会：
- 竞品 A 重企业市场，对个人用户支持弱
- 建议切入"个人创作者+小团队"细分市场，按月订阅 29 元档
```

### 2.2 用户画像提炼

**场景说明**：基于现有数据或假设，生成详细的用户画像（Persona），用于产品设计和营销定向。

**提示词模板**：

```
你是一位用户研究专家，擅长从数据中提炼精准用户画像。

请基于以下信息，生成 2-3 个核心用户画像：
- 产品/服务：[填入产品名称]
- 已有用户数据：[填入你掌握的数据，如年龄分布、职业、使用场景、付费意愿等；如果没有，写"基于假设"]
- 产品解决的核心问题：[填入问题]
- 当前主要获客渠道：[填入渠道，如"小红书/SEO/转介绍"]

每个用户画像请包含：
1. 基础信息：
   - 姓名（化名）、年龄、性别、城市、职业、收入区间
   - 教育背景、家庭状况
2. 行为特征：
   - 日常使用哪些 App/工具
   - 信息获取渠道（关注哪些博主/公众号/社群）
   - 消费习惯（价格敏感度、决策周期）
3. 痛点与需求：
   - 当前最头疼的 3 个问题
   - 尝试过哪些解决方案，为什么不满意
   - 对理想产品的期望
4. 使用场景：
   - 何时会使用你的产品
   - 使用频率和时长
   - 典型的使用路径
5. 营销触达建议：
   - 什么文案/钩子能吸引 TA
   - 最佳触达渠道和时间
   - 转化路径设计
6. 一句话描述："我是一个______，我需要______，因为______"
```

**使用建议**：画像生成后，建议找 3-5 个真实用户访谈验证，避免"想象中的用户"偏差。

**预期输出示例**：

```
用户画像 1：高效小李
- 28 岁，一线城市产品经理，年薪 25-35W
- 痛点：每天写大量文档，想提升效率但不想学复杂工具
- 使用场景：周日晚规划下周工作内容时打开产品
- 触达建议：在小红书/即刻发"产品经理效率工具"类内容
- 一句话：我是一个追求效率的产品经理，我需要快速产出高质量文档，因为我不想加班。
```

### 2.3 商业模式画布填充

**场景说明**：用商业模式画布（Business Model Canvas）系统化梳理你的创业想法。

**提示词模板**：

```
你是一位商业模式设计顾问，擅长用精益画布帮助创业者验证想法。

请基于以下信息，帮我填充一份商业模式画布：
- 创业项目：[填入项目名称]
- 一句话描述：[填入项目做什么]
- 目标用户：[填入用户群体]
- 解决什么问题：[填入核心痛点]
- 解决方案：[填入你的产品/服务如何解决问题]
- 目前已有的资源/优势：[填入你的独特资源、技能、人脉等]
- 初步定价想法：[填入价格设想]

请按以下 9 个模块输出，每个模块包含：
1. 当前假设（基于你提供的信息）
2. 需要验证的关键问题（至少 2 个）
3. 验证方法建议（低成本验证方式）

9 个模块：
1. 客户细分（Customer Segments）
2. 价值主张（Value Propositions）
3. 渠道通路（Channels）
4. 客户关系（Customer Relationships）
5. 收入来源（Revenue Streams）
6. 核心资源（Key Resources）
7. 关键业务（Key Activities）
8. 重要合作（Key Partnerships）
9. 成本结构（Cost Structure）

最后，请给出：

**预期输出示例**：

- 当前假设：25-35 岁一线城市职场人，有副业意愿但缺方法

   - 临时止损方案（如果需要）
4. 修复方案：
   - 推荐方案及原因
   - 备选方案
   - 修复影响范围评估
5. 预防措施：
   - 如何避免同类 Bug 再次发生
   - 是否需要补充监控/告警
   - 是否需要更新测试用例
6. 沟通模板：
   - 给用户的回复话术（如需对外沟通）
   - 给团队内部的同步简报
```

**使用建议**：对于偶发 Bug，优先加监控和日志，比盲目猜测根因更有效。

**预期输出示例**：

```
根因分析（Top 3）：
1. 60% 可能：缓存穿透导致数据库雪崩（验证：检查 Redis 命中率）
2. 25% 可能：新发布引入的并发问题（验证：回滚后是否复现）
3. 15% 可能：第三方 API 超时未兜底（验证：查看外部调用日志）

临时止损：
- 立即开启限流
- 降级读取缓存，允许短暂数据不一致
```

### 5.1 每日工作计划生成

**场景说明**：基于长期目标和当前任务池，生成优先级清晰的每日工作计划。

**提示词模板**：

```
你是一位效率教练，擅长帮助创业者在信息过载中聚焦优先级。

- 我的长期目标（本季度）：[填入 1-3 个核心目标]
- 当前在进行的项目：[列出 2-5 个进行中项目]
- 待办任务池：[列出所有待办，不区分优先级]
- 今日可用时间：[如"9:00-12:00, 14:00-18:00"]
- 精力高峰期：[上午/下午/晚上]
- 必须今日完成的事（如有）：[填入硬 deadline 事项]
- 精力状态：[满分 10 分，今日几分]

请输出：
1. 今日 TOP 3 优先级任务：
   - 每个任务标注：预计耗时、与哪个长期目标关联、成功标准
   - 按"吃青蛙"原则，最困难/最重要的事放精力高峰期
2. 时间块安排：
   - 按时间段划分（每块 60-120 分钟）
   - 包含专注工作、会议/沟通、休息缓冲
3. 需要推迟/委派的事项：
   - 说明为什么不是今天做
4. 今日能量管理建议：
   - 根据精力状态给出的休息/运动/饮食建议
5. 晚间复盘检查点：
   - 3 个简单问题，用于一天结束时快速回顾

原则：
- 不超过 3 件核心任务
- 预留 20% 缓冲时间应对突发
- 区分"紧急"和"重要"，优先做重要的事
```

**使用建议**：每天早晨花 5 分钟执行此提示词，比直接开工效率高 30% 以上。

**预期输出示例**：

1. [产品] 完成落地页文案终稿（2h，关联目标：本月上线 MVP）
2. [获客] 发布小红书第 3 篇笔记（1.5h，关联目标：建立内容渠道）

时间块：
09:00-11:00  专注：落地页文案（精力高峰）
11:00-11:30  休息 + 轻量邮件
11:30-12:30  专注：客户修改意见
14:00-15:30  专注：小红书笔记
...

晚间复盘：
1. 今天的 TOP 3 完成了几个？
2. 最大的时间黑洞是什么？
3. 明天需要调整什么？
```

### 5.2 周复盘报告撰写

- 本周实际完成事项：[列出所有完成的事，大事小事都写]
- 本周未完成事项：[列出计划做但没做的事]

- 本周遇到的障碍：[填入问题、意外、情绪波动等]

4. 情绪/能量管理：

**使用建议**：复盘不是检讨。即使一周"什么都没成"，也能沉淀"这个方向可能不对"的宝贵认知。

### 6.1 合同条款审查

**场景说明**：快速审查合同中的风险点，特别适用于与客户的项目合同、平台入驻协议等。

**提示词模板**：

```
你是一位熟悉商业合同的法律顾问（非执业律师，建议关键合同仍咨询执业律师）。

请帮我审查以下合同/协议：
- 合同类型：[项目服务合同 / 平台入驻协议 / 合伙协议 / 版权授权 / 劳动合同]
- 我方角色：[甲方 / 乙方 / 平台方 / 服务方]
- 合同关键背景：[交易金额、合作周期、核心交付物]
- 我已知的顾虑：[填入你特别担心的点]

合同内容：
```[粘贴合同文本]```

请输出：
1. 风险评级：高/中/低风险概览
2. 逐条审查意见：
   - 对关键条款（付款、交付、违约、知识产权、保密、争议解决）逐一分析
   - 标注：对我方有利/中性/不利
   - 不利条款给出修改建议话术
3. 缺失的重要条款：
   - 这类合同通常应该有但本文缺失的条款
   - 补充建议
4. 谈判建议：
   - 哪些条款必须坚持
   - 哪些可以妥协
   - 让步的交换条件建议

   - 任何可能导致重大损失的条款

免责声明：你的分析仅供参考，不构成法律意见。涉及重大金额或复杂权益的合同，请务必咨询执业律师。
```

**使用建议**：所有合同都要看清"争议解决"条款，约定在己方所在地法院/仲裁可以大幅降低维权成本。

**预期输出示例**：

- 建议修改为：逾期按日 0.05% 计违约金，无上限

缺失条款：
- 未约定知识产权归属，建议补充：交付物著作权归我方，客户仅有使用权

危险信号：
- 第 12 条：自动续约，需提前 90 天书面通知才能终止
- 建议改为：到期需双方书面确认续约

### 6.2 数据洞察报告

**场景说明**：将原始数据转化为可行动的洞察，适用于用户行为、营销效果、产品数据等分析。

**提示词模板**：

```
你是一位数据分析师，擅长从数据中发现业务机会。

请基于以下数据生成洞察报告：
- 分析主题：[用户增长分析 / 营销效果复盘 / 产品功能使用分析 / 收入结构分析]

- 原始数据：[粘贴数据，可以是表格、CSV 文本或关键指标]
- 业务背景：[当前处于什么阶段，面临什么问题]
- 已知假设：[你对数据的初步判断]

请输出：
1. 数据概览：
   - 核心指标一览（本期 vs 上期/目标）
   - 用一句话概括数据整体表现
2. 关键发现（至少 3 点）：
   - 支持发现的数据证据
   - 该发现对业务的含义
3. 异常点识别：
   - 与预期不符的数据点
   - 可能的解释和验证方法
4. 细分洞察：
   - 按用户群/渠道/时间等维度拆分后的发现
   - 哪个子群体表现最好/最差

   - 数据建议我们做什么（Start/Stop/Continue）
   - 每个建议的预期影响和优先级
6. 需要进一步分析的问题：
   - 数据无法回答的关键问题
   - 获取答案需要补充的数据或实验
7. 可视化建议：
   - 如果要做汇报，建议用什么图表展示哪些数据

要求：每个结论都要有数据支撑，避免"我感觉"。
```

**使用建议**：数据报告的价值不在"描述发生了什么"，而在"建议下一步做什么"。

**预期输出示例**：

- [高优先级] 重新设计落地页首屏，增加社会证明
- [中优先级] 将邮件推送时间从周日改为周四
```

## 附录：提示词使用技巧

### 通用优化原则

| 技巧 | 说明 | 示例 |
|------|------|------|
| **角色设定** | 给 AI 一个具体身份，输出质量提升 30%+ | "你是一位转化率优化专家..." |
| **输出格式** | 明确指定格式（表格/列表/代码块） | "请以表格形式输出..." |
| **范围限定** | 限定字数、数量、时间，避免泛泛 | "提供 3 个备选，每个 15 字内" |
| **示例引导** | 给一个示例，AI 更容易理解你的风格 | "类似这样的风格：[示例]" |
| **约束条件** | 说明不要什么，和要什么的价值等同 | "避免使用专业术语" |

### 快速迭代流程

1. **第一版**：复制模板，填入你的信息，生成初稿
2. **第二版**：告诉 AI "这个方向对，但太泛了，请聚焦在 [具体方向]"
3. **第三版**："很好，请在这个基础上 [添加某元素 / 调整语气 / 压缩到 X 字]"

> 💡 **核心心法**：把 AI 当作一位能力很强的实习生——你描述得越具体，产出越惊艳。
