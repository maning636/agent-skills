# 三层预算工具配置

用于按 OPC 当前收入、技术能力和业务类型选择工具栈。默认原则：先跑通收入闭环，再升级工具；先买“产出工具”，后买“管理工具”。

## 按收入选型

```
月收入 < ¥5000
└── 基础版：0-500元/月，目标是验证商业模式

月收入 ¥5000-20000
└── 标准版：500-2000元/月，目标是提升质量和效率

月收入 > ¥20000
└── 专业版：2000元+/月，目标是自动化、稳定性和规模化
```

## 基础版：验证期

| 职能 | 推荐组合 |
|------|----------|
| 大模型 | 豆包、DeepSeek、Kimi、Qwen 免费版 |
| 设计 | Canva Free、稿定设计、即梦、通义万相 |
| 自动化 | 飞书捷径、集简云免费版、Zapier Free、GitHub Actions |
| 协作 | 飞书免费版、Notion Free、腾讯文档 |
| 网站 | Vercel、Notion、Carrd、上线了 |

升级信号：免费额度成为交付瓶颈，或单个工具每月节省的时间价值超过其价格3倍。

基础版不要购买：企业级CRM、复杂BI、自托管知识库、多模型网关、批量社媒工具。

## 标准版：稳定运营

| 职能 | 推荐组合 |
|------|----------|
| 大模型 | ChatGPT Plus、Claude Pro、Kimi/Qwen API |
| 设计 | Midjourney、Canva Pro、Figma |
| 自动化 | n8n、Zapier Pro、Make、集简云付费版 |
| 客户管理 | 飞书多维表格、HubSpot Free、企微 |
| 内容获客 | 5118、新榜、公众号/小红书数据工具 |

核心逻辑：只在“质量提升10%能带来收入提升”的环节付费。

## 专业版：规模化

| 职能 | 推荐组合 |
|------|----------|
| 模型 | 多模型 API、模型路由、私有知识库 |
| 开发 | Cursor、GitHub、Vercel/云服务器、监控告警 |
| Agent | Dify 自托管、LangGraph、n8n、MCP Server |
| 数据 | 数据库、BI看板、自动周报 |
| 合规 | 权限控制、日志审计、备份策略 |

## 输出建议

给用户配置方案时，必须包含：

1. 当前阶段推荐的最小工具栈。
2. 不建议购买的工具和理由。
3. 下一个升级阈值。
4. 月度预算上限，建议不超过月收入的20%。

## 工具保留规则

每月复盘一次：

| 问题 | 决策 |
|------|------|
| 这个工具是否直接服务获客、转化、交付或复盘？ | 否则取消 |
| 本月是否使用≥5次？ | 否则取消或降级 |
| 节省的时间价值是否超过成本3倍？ | 否则寻找替代 |
| 是否有同类工具重复？ | 只保留一个主工具 |
