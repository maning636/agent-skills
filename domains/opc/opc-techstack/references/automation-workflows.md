# 自动化工作流

用于帮助 OPC 把重复工作交给 Agent、n8n、Zapier、Make 或 MCP 工作流。不要一开始追求全自动，先自动化最稳定、最高频、最耗时的任务。

## 选择自动化体系

| 体系 | 门槛 | 适合场景 | 典型工具 |
|------|------|----------|----------|
| 无代码自动化 | 低 | 表单、邮件、CRM、通知、简单分发 | Zapier、Make、集简云 |
| 工作流编排 | 中 | 多步骤、条件分支、数据处理 | n8n、Dify Workflow |
| Agent 自动化 | 中高 | 选题、客服、数据分析、报告生成 | Coze、Dify、LangGraph |
| MCP 工具链 | 高 | 连接数据库、浏览器、代码仓库、内部系统 | MCP Server、Playwright MCP |

## 高 ROI 工作流

### 获客工作流

```
表单/私信/邮件
  → 自动写入 CRM
  → AI 判断意向等级
  → 高意向转人工
  → 低意向进入内容培育列表
```

### 内容工作流

```
RSS/关键词/竞品监控
  → AI 生成选题建议
  → 人工选择
  → AI 生成草稿
  → 人工注入经验与案例
  → 多平台差异化发布
  → 数据回收与复盘
```

### 客服工作流

```
客户问题
  → 知识库检索
  → AI 回复标准问题
  → 触发条件转人工
  → 自动记录问题类型
  → 更新 FAQ 和销售话术
```

### 数据周报工作流

```
各平台数据
  → 自动汇总到表格或数据库
  → AI 识别异常
  → 生成周报
  → 推送到飞书/微信
  → 形成下周行动清单
```

## 自动化优先级评分

每个候选任务按 1-5 分评分：

| 维度 | 判断 |
|------|------|
| 频率 | 每天发生优先于每月发生 |
| 标准化 | 输入输出稳定，规则清晰 |
| 时间成本 | 每周节省时间越多越优先 |
| 出错代价 | 出错代价低的先自动化 |
| 收入影响 | 直接影响获客、转化、交付优先 |

优先自动化总分 ≥18 的任务。

## 人工介入边界

- 客单价超过 ¥5000 的售前咨询要转人工。
- 合同、报价、退款、投诉必须保留人工确认。
- 对外发布内容必须人工审核事实、案例和合规风险。
- 涉及客户敏感数据的流程要优先考虑权限和日志。
