# 赛道自评打分表

> **用途**：在决定投入某个AI赛道前，用三维度模型客观评估机会质量，避免盲目入场。

---

## 一、三维度模型打分表

这是 `opc-strategy` 的主评分标准。`需求刚性 / 技术成熟度 / 变现清晰度` 分别对应正文里的 L/T/M 模型：L/T/M 用于理解等级，本表用于最终决策。

对每个维度下的指标进行1-10分打分（1=极差，10=极好）。

### 维度A：需求刚性（权重建议：35%）

| 指标 | 评分标准 | 得分（1-10） |
|:---|:---|:---:|
| A1 目标用户是否明确 | 能否用一句话描述典型用户画像 | |
| A2 需求是否真实存在 | 用户是否已经在用替代方案解决该问题 | |
| A3 需求频次高低 | 是每日/每周/每月一次，还是一次性需求 | |
| A4 付费意愿强度 | 用户是否习惯为此类服务付费 | |
| A5 市场容量大小 | 潜在用户数 × 客单价估算 | |
| **维度A小计** | | **/50** |

### 维度B：技术成熟度（权重建议：30%）

| 指标 | 评分标准 | 得分（1-10） |
|:---|:---|:---:|
| B1 当前AI能力是否足够 | 现有模型能否直接满足核心需求 | |
| B2 实现复杂度 | 是否需要大量定制开发/微调 | |
| B3 技术风险可控性 | 模型幻觉、延迟、稳定性是否在可接受范围 | |
| B4 技术迭代友好度 | 模型升级是否容易带来产品提升 | |
| B5 技术壁垒高低 | 竞争对手复制的难度 | |
| **维度B小计** | | **/50** |

### 维度C：变现清晰度（权重建议：35%）

| 指标 | 评分标准 | 得分（1-10） |
|:---|:---|:---:|
| C1 商业模式是否清晰 | 订阅/按需/分成/广告等模式是否明确 | |
| C2 客单价与LTV估算 | 单次收费多少，用户生命周期价值 | |
| C3 获客渠道是否明确 | 是否有低成本/可规模化的获客方式 | |
| C4 回款周期长短 | 从交付到收款的周期 | |
| C5 利润空间大小 | 收入扣除成本后的毛利率估算 | |
| **维度C小计** | | **/50** |

## 二、加权评分区

| 维度 | 原始总分（/50） | 换算百分制 | 自定义权重 | 加权得分 |
|:---|:---:|:---:|:---:|:---:|
| A 需求刚性 | | =原始/50×100 | ____% | =百分制×权重 |
| B 技术成熟度 | | =原始/50×100 | ____% | =百分制×权重 |
| C 变现清晰度 | | =原始/50×100 | ____% | =百分制×权重 |
| **加权总分** | — | — | **100%** | **/100** |

### 快速计算示例

```
加权总分 = (A小计÷50×100 × A权重) + (B小计÷50×100 × B权重) + (C小计÷50×100 × C权重)
```

| 示例 | A | B | C | 总分 |
|:---|:---:|:---:|:---:|:---:|
| 示例1：AI简历优化 | 42→84×0.35=29.4 | 38→76×0.30=22.8 | 35→70×0.35=24.5 | **76.7** |
| 示例2：AI法律助手 | 45→90×0.35=31.5 | 32→64×0.30=19.2 | 40→80×0.35=28.0 | **78.7** |
| 示例3：AI儿童绘本 | 38→76×0.35=26.6 | 44→88×0.30=26.4 | 30→60×0.35=21.0 | **74.0** |

## 三、总分解读

| 总分区间 | 决策建议 | 行动方向 |
|:---:|:---|:---|
| **< 60分** | **建议放弃** | 核心维度存在硬伤，寻找其他赛道 |
| **60-79分** | **谨慎验证** | 只做低成本MVP，控制在2周内/500元内 |
| **≥ 80分** | **进入7天付费验证** | 立刻访谈和做MVP，不急着开发完整产品 |

### 细化解锁条件

| 条件 | 说明 |
|:---|:---|
| 任一维度<30/50 | 该维度为硬伤，先补证据或换方向 |
| 变现清晰度<30/50 | 无论总分多高，都不能进入开发 |
| 需求刚性>40且变现清晰度>40 | 可优先启动，技术问题可边做边解决 |
| 访谈后无人愿意付费 | 分数作废，重新选择用户或痛点 |

---

## 使用方法

1. **确定赛道**：用一句话描述你要评估的赛道（如"面向应届生的AI简历优化服务"）。
2. **逐项打分**：根据当前真实情况打分，不要乐观估计。
3. **调整权重**：根据你的风险偏好调整三维度权重（总和必须为100%）。
4. **计算总分**：填入加权评分区，得出最终分数。
5. **对照解读**：查看总分区间和解锁条件，做出决策。

## 填写说明

- **诚实第一**：打分过高会导致误判，建议找第三方帮你复核。
- **数据优先**：能用数据不用感觉，如"市场容量"尽量估算具体数字。
- **定期复评**：技术迭代快，建议每3个月复评一次。
- **多赛道对比**：同时评估2-3个赛道，选分最高的。
