# 财税合规与节税

用于帮助 AI 一人公司建立最低可行财税体系。优先保证合规，再讨论节税。

## 三条铁律

1. **所有稳定业务收入走对公账户**：客户付款、平台结算、海外回款都要有可追踪流水。
2. **所有成本留存凭证**：合同、发票、账单、支付记录、用途说明至少保存5年。
3. **按时申报**：小规模纳税人通常按季度申报增值税和企业所得税，工资个税按月申报。

## 新手最低可行财税体系

| 阶段 | 动作 | 不做什么 |
|------|------|----------|
| 付费验证前 | 记录每笔收入、支出和聊天确认 | 不为节税复杂注册 |
| 第一笔企业订单 | 签合同，确认发票和付款主体 | 不用个人微信长期收B端款 |
| 月收入稳定 | 开对公账户，找代账，建立凭证库 | 不混用公司账户和个人消费 |
| 利润稳定 | 讨论工资、分红、成本归集 | 不虚开发票或虚构成本 |

## AI 行业可归集成本

| 成本类型 | 示例 | 凭证要求 |
|----------|------|----------|
| 算力与云资源 | ECS、GPU、数据库、对象存储、CDN | 发票、控制台账单、业务用途说明 |
| 模型与 API | OpenAI/Anthropic/DeepSeek/Qwen/API代理 | 合规发票、Invoice、付款记录 |
| AI 工具订阅 | ChatGPT、Claude、Midjourney、Canva、Cursor | 发票或账单、订阅记录 |
| 软件与自动化 | GitHub、Vercel、n8n、Zapier、Make | 发票、合同、账单 |
| 营销获客 | 广告投放、设计外包、内容制作 | 发票、投放后台截图、交付记录 |
| 知识产权 | 软著、商标、专利代理 | 发票、证书、申请材料 |

## 节税动作优先级

1. **先建账**：没有账和凭证，所有节税方案都不可用。
2. **成本抵扣**：把真实业务成本合规入账，降低应纳税所得额。
3. **工资+分红组合**：利润稳定后，给创始人发合理工资通常比分红更灵活。
4. **小微企业政策**：优先使用小规模纳税人和小微企业优惠。
5. **研发费用归集**：工具产品、Agent、SaaS开发成本可尝试按研发项目归集。

## 每月凭证文件夹

```
2026-05/
├── 01-income/          # 合同、订单、发票、回单
├── 02-ai-tools/        # 模型、API、SaaS订阅
├── 03-infra/           # 服务器、域名、数据库
├── 04-marketing/       # 广告、设计、内容外包
├── 05-delivery/        # 外包、素材、交付记录
└── 06-notes.md         # 本月异常说明和待问代账问题
```

## 风险提醒

- 海外 SaaS 和 API 费用要保留 Invoice、付款凭证和用途说明，必要时咨询代扣代缴情形。
- 不建议为了“节税”虚开发票或虚构成本。
- 财税政策存在地域差异，落地前应让本地代账或税务顾问复核。

## 建议输出

回答用户时先给“合规底线”，再给“节税路径”，最后给“本月能执行的清单”。
