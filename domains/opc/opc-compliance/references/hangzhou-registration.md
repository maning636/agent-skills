# 杭州AI一人公司注册全流程（2026版）

> 基于 OPC Space 实战经验整理。全程线上办理，7天内拿照，总费用不超过1000元。

## 注册前准备

### 材料清单

| 材料 | 说明 | 备注 |
|------|------|------|
| 法人身份证 | 正反面照片 | 你自己 |
| 监事身份证 | 正反面照片 | 信任的朋友，非挂名 |
| 财务负责人身份证 | 正反面照片 | 可以填自己 |
| 注册地址 | 房产证或租赁合同 | 没地址看园区方案 |
| 公司名称 | 3-5个备选 | 杭州+字号+行业+有限公司 |
| 注册资本 | 建议30万 | 5年内实缴，可用知识产权实缴 |
| 经营范围 | 从系统勾选 | AI公司建议全勾 |

### AI公司建议经营范围

- **技术类（必勾）**：技术服务、技术开发、人工智能应用软件开发、数据处理和存储支持服务、信息系统集成服务
- **信息服务类**：互联网信息服务、广告设计/代理/发布、教育咨询服务、企业管理咨询
- **销售类**：计算机软硬件及辅助设备零售、互联网销售

## 注册流程（7天）

### Day 1：核名（10分钟）

打开"浙里办"APP → 搜索"企业开办" → "名称自主申报"

命名格式：**杭州 + 字号 + 行业 + 有限公司**

### Day 2：填写设立登记（30分钟）

- 注册地址：实际地址或园区地址
- 注册资本：30万，认缴期限写20年
- 股东：你自己，100%
- 法定代表人：你自己
- 监事：朋友（不能和法人是同一人）
- 财务负责人：你自己
- 经营范围：全勾上
- 公司章程：系统自动生成

### Day 3：电子签名（10分钟）

浙里办APP → "市场监管" → "电子签章"

**注意**：你自己和监事都要签。监事不在身边？发签名链接给他微信签。

### Day 4-5：等待审核（1-3工作日）

常见驳回原因：
- 地址证明材料不清晰 → 重新拍，四角完整
- 经营范围有前置审批项目 → 删掉（如"教育培训"需办学许可证）
- 监事和法人是同一人 → 必须换人
- 公司名重名 → 换字号

### Day 6-7：领执照 + 刻章

- 电子执照：即时可用
- 纸质执照：邮寄到家，免费
- 刻章：杭州多区免费（上城/西湖/滨江等）

## 一人公司特殊风险

### 人格混同（《公司法》第63条）

一人公司股东不能证明财产独立的，承担**连带责任**（举证责任倒置）。

**红线行为**：
- 个人微信收公司款
- 公司账户付个人消费
- 无合同/无发票的资金往来

**防火墙措施**：
- 所有收支走对公账户
- 每年做审计报告（2000-5000元）
- 保留完整财务凭证
- 找一个可信赖的监事

### 监事的真正作用

监事不是挂名，是公司治理的保险栓：
- 检查公司财务
- 监督董事/高管
- 发现损害公司利益时要求纠正
- 证明公司有基本治理结构（非一人独断）

**找谁当监事**：绝对信任、不参与经营、长期稳定、能联系上。每年给监事发一次财务报表，保留微信记录。
