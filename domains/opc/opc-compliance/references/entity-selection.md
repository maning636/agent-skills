# 主体选择决策树

用于在 OPC 创业早期选择个体户、有限公司或有限合伙。默认建议：如果不是纯试水，优先选择有限责任公司。

## 快速判断

```
年收入预计？
├── <5万/年 → 个体户可短期试水，最长不超过6个月
├── 5-15万/年 → 个体户核定征收或小规模有限公司，结合客户类型判断
└── >15万/年 → 有限责任公司

主要客户是谁？
├── 个人客户为主 → 个体户/有限公司均可，但保留升级计划
└── 企业客户为主 → 有限责任公司，便于签合同、开票、走对公

是否需要软著、商标、平台入驻或融资？
├── 是 → 有限责任公司
└── 否 → 可先轻量验证，但收入稳定后升级
```

## 三类主体对比

| 维度 | 个体工商户 | 有限责任公司 | 有限合伙企业 |
|------|------------|--------------|--------------|
| 适用阶段 | 副业试水、个人接单 | 正式创业、长期经营 | 融资预备、股权设计 |
| 注册成本 | 低 | 中 | 高 |
| 责任承担 | 无限责任 | 有限责任，需避免人格混同 | GP无限，LP有限 |
| 对公收款 | 可弱化但不建议 | 必须建立 | 必须建立 |
| 企业客户接受度 | 较弱 | 强 | 强 |
| 融资与知识产权 | 受限 | 友好 | 友好但复杂 |

## 一人公司红线

- 不用个人微信或支付宝收公司业务款。
- 不用公司账户支付个人消费。
- 不长期占用公司资金，股东借款超过一年可能被视同分红。
- 保留合同、发票、银行回单和交付凭证。

## 建议输出

给用户建议时必须同时说明：

1. 当前最适合的主体类型。
2. 触发升级的收入、客户或合规条件。
3. 需要立刻建立的风险隔离动作。
