# 第 10 关 · 后端运维

> 原理见《Vibe Coding》系列第 10 章 ｜ 产物: `.vibe/launch.md`「后端运维」段 ｜ 过关: `gate.mjs check 10`（has_server=true 才走；Vercel+托管库党自动跳过）

## 陪跑流程

1. 选型原则一句话：**起步够用就好，不够再在线升配**（轻量 2 核 2-4G 起步，别上来 ECS 高配）。用 ①。
2. 服务器到手**立刻加固**（公网机器几小时内就会被扫），跑 ① 生成的脚本——但有两条保命纪律：改 SSH 端口后云安全组也要放行；重启 sshd 前另开窗口验证新配置能登录，别把自己锁外面。
3. 有后端就上 Docker Compose（②），一份 yml 换服务器原样跑。
4. 图片/大文件走对象存储 + CDN（R2 免出口流量费），别吃服务器带宽。
5. 全部落 launch.md「后端运维」段 → `gate check 10`。出问题用 ③ 排错。

## Prompt ① 选型 + 初始化加固脚本

```
我要上一台云服务器跑 [什么后端]，用户在 [地区]，日活约 [多少]，预算 [多少]。
1. 推荐：轻量还是 ECS、几核几 G、带宽、盘、地域，说理由
2. 生成首登初始化加固脚本：建非 root 用户、ed25519 密钥登录、关密码登录、
   改 SSH 端口、装 fail2ban、防火墙只开 80/443 和新 SSH 端口
每条命令加注释，标出哪步先做、怎么避免把自己锁在外面。
```

## Prompt ③ 运维排错（工具型，随用随跑）

```
服务器出问题：[现象，如"502 / 磁盘满 / 带宽打满"]。环境：[配置 + Docker/面板]。
1. 最可能的原因按概率排序 2. 逐条排查命令（日志/进程/磁盘/带宽）3. 修复办法
```

提醒：AI 给的服务器命令**先看懂再敲**——涉防火墙/SSH 的配错一条就把自己锁外面。
