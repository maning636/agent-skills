# 第 7 关 · 审美第一屏

> 原理见《Vibe Coding》系列第 7 章 ｜ 产物: `.vibe/crap-check.md` ｜ 过关: `gate.mjs check 7`（internal 形态自动跳过）

## 陪跑流程

1. 核心动作只有一个：**把第一屏做到 90 分，其余 60 分就行**。第一屏必须有一个"能停下来的地方"（大标题 / 强对比主按钮 / 一张有细节的图，任选其一做到位）。
2. 用户截图第一屏 → ① CRAP 评审 → 按最该先动的 3 条改。
3. 需要整套观感统一时跑 ②，重做第一屏用 ③。
4. 改完做 3 米测试，把结果落 crap-check.md（焦点写具体的那一个）→ `gate check 7`。

## Prompt ① CRAP 评审（结果落产物）

```
你是熟悉《Refactoring UI》原则的资深 UI/UX 设计师。
这是我的第一屏截图：[上传截图]
按 视觉层级/对比/间距节奏/对齐网格/字体可读性/一致性 逐项挑毛病，
每条给：位置、违反了哪条原则、严重度（高/中/低）、怎么改。挑出最该先动的 3 条。
改完后，把四项结论按 .vibe/crap-check.md 的 CRAP 自查格式勾选，焦点写进「第一屏焦点」段。
```

## Prompt ② 设计 tokens

```
基于产品风格 [一句话：如"干净、偏科技感、主色蓝"]，生成一套直接能用的设计 tokens：
- 配色：主色阶 + 语义色（正文/背景/主按钮/危险），正文对比度达 WCAG AA
- 间距：4/8px 基准阶梯（4 8 16 24 32 48 64）
- 字号：一套阶梯并标注每档用途
输出 CSS 变量或 Tailwind 配置，直接贴进项目。
```

## Prompt ③ 第一屏冲 90 分

```
重做产品第一屏（hero）。产品：<<注入 .vibe/vdf.md 的 V 段>>
要求：必须有一个明显视觉焦点（大标题/强对比主按钮/一张有细节的图，任选其一做到位），
用上面那套 tokens，主按钮"3 米外能看见"。其余先不管——只要第一屏跨过"像产品"这条线。
```

提醒：AI 出的配色排版是起点不是终点——拿一个你觉得"专业"的网站，把它的色值间距喂给 AI 当基准。模仿 100 个好页面，比凭空生成 100 次有用。
