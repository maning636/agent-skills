# 第 9 关 · Web 上线

> 原理见《Vibe Coding》系列第 9 章 ｜ 产物: `.vibe/launch.md`「Web 上线」段 ｜ 过关: `gate.mjs check 9`（仅 form_factor=web）

## 陪跑流程

1. 用 ① 定部署路径（纯前端 / 大陆云服务器 / 海外 PaaS——按用户在哪、验证还是正经做）。
2. **备案是前置条件不是补丁**：决定用大陆服务器的当天就启动 ICP 备案（约 7-22 个工作日），用 ② 列材料。备案期间海外环境先内测攒种子用户，不干等。
3. 安全走 ③——注意：**密钥进环境变量、接口限流这两条第 8 关已审过**，这里只确认它们在生产环境仍成立，不重审。
4. 结论与勾选落 launch.md「Web 上线」段（5 项全勾 + 备案决策写明）→ `gate check 9`。

```
帮我把项目上线选部署方案并给步骤。
项目与形态：<<注入 .vibe/vdf.md 的 V 段>>；用户主要在 [大陆/海外]；现在是 [验证阶段/正经做]。
1. 推荐一条部署路径，说清为什么（速度、要不要备案、运维省不省心）

3. 数据库给托管方案，别让我从零搭
把结论写进 .vibe/launch.md「Web 上线」段的 部署方式/域名/备案决策 三行。
```

## Prompt ② 备案材料 + 流程

```

2. 完整步骤和周期，标出工信部/管局环节急不得

```

## Prompt ③ 上线安全自查（与第 8 关去重）

```
项目技术栈与部署：[填]。生成上线前安全自查清单，每条写"确认什么、怎么确认"：
- 全站强制 HTTPS（http 跳转）
- 服务器只开必要端口、SSH 用密钥、无 root 裸跑
- 数据库自动备份 + 可用性监控告警（新手最常漏的两条）
- 另起一条：确认第 8 关已审的「密钥进环境变量 / 接口限流」在生产环境仍成立
按 .vibe/launch.md「Web 上线」段的清单逐项对应，确认一项勾一项。
```

## 过关前自查

- 用真实手机、真实网络访问过一遍吗？陌生人能正常打开才算上线
- 备案决策和你的市场自洽吗（主打大陆却没启动备案 = 定时炸弹）
