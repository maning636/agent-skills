# 第 11 关 · App / 小程序上架

> 原理见《Vibe Coding》系列第 11 章 ｜ 产物: `.vibe/launch.md`「App / 小程序上架」段 ｜ 过关: `gate.mjs check 11`（form_factor=app/miniapp）

## 陪跑流程

1. 这一关的翻车点不是写功能，是**审核与资质**：软著普通 2-3 个月、ICP 备案约 7-22 工作日、平台审核几天——**可以并行办，最慢的那条决定上线日**。用 ① 列全并当天启动。
2. 提审前用 ② 防驳回自查（把驳回挡在提交前）。
3. 被拒是常态不是判死刑：用 ③ 照拒审条款改那一处，别跟审核员狡辩。
4. 结论落 launch.md「App / 小程序上架」段 → `gate check 11`。

## Prompt ① 形态确认 + 资质清单

```
产品：<<注入 .vibe/vdf.md 的 V 段>>，变现方式：<<注入 .vibe/pricing.md 的「模型与价格」段（若已有）>>

```

## Prompt ② 提审防驳回自查

```
我要把 [iOS App / 国内安卓 / 微信小程序] 提审，产品 [一句话]。生成提审前自查清单，专打该平台最易被拒的点：
- iOS：套壳(4.2)、隐私没填全(5.1)、数字收费没走内购(3.1——国内必须内购)
- 国内安卓：软著/备案齐没、隐私政策、多余权限
- 小程序：类目匹配、隐私指引与代码调用一致、信息填全
每条写成能逐条勾的动作。
```
