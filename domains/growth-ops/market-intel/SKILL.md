# 市场情报 (market-intel)

## 1. 适用边界

### 1.1 适用场景
- 新业务立项的市场评估
- 现有业务的扩张方向选择
- 年度战略规划的市场输入
- 投资 / 收并购尽调
- 新地域 / 新客群的市场验证

### 1.2 不适用
- 单个客户调研（属 `user-research` skill）
- 竞品分析（属 `competitor-analysis` skill）
- 技术趋势（属 `trend-analysis` skill）

## 2. 市场规模测算（TAM-SAM-SOM）

### 2.1 三层模型

```
TAM（Total Addressable Market）    全市场，所有可能客户 × 客单价
  ↓
SAM（Serviceable Available Market）   可服务市场，去除地理/品类/合规限制
  ↓
SOM（Serviceable Obtainable Market） 实际可获取市场，去除竞争 + 自家能力限制
```

### 2.2 测算方法（4 种）

#### 自上而下（Top-Down）
```
TAM = 行业总规模 × 相关品类占比
SAM = TAM × 地理覆盖比例 × 客群匹配度
SOM = SAM × 预期市场份额（参考对标）
```
适用：成熟行业、有公开数据
例：中国 SaaS 市场 $100B × CRM 占比 15% = TAM $15B

#### 自下而上（Bottom-Up）
```
SOM = 目标客户数 × 渗透率 × 客单价
TAM = SOM / 现实市场份额
```
适用：创业公司、需要说服投资人
例：可触达 10,000 SMB × 5% 渗透 × $5k/y = SOM $2.5M

#### 价值理论（Value Theory）
```
市场价值 = 客户获得的收益 × 客户数
TAM = 节省时间 × 时薪 × 用户数
```
适用：颠覆性创新，没有直接对标
例：AI 节省每周 5h × $50/h × 100万用户 = TAM $13B/年

#### 第三方报告
直接引用 Gartner / IDC / 艾瑞 / CB Insights 等数据
**注意**：标注来源 + 日期 + 方法论差异

### 2.3 验证（多方法交叉）

用 ≥ 2 种方法测算，结果差异 > 50% 需要重新审视：
- 客单价假设是否合理
- 客户数估算是否有误
- 增速假设是否过度乐观

## 3. 市场细分（Segmentation）

### 3.1 细分维度

| 维度 | 例子 |
|------|------|
| 客户类型 | 企业 / SMB / 个人 |
| 行业 | 金融 / 医疗 / 教育 / 零售 |
| 地理 | 北美 / EMEA / APAC / 中国 / 日本 |
| 用户角色 | 决策者 / 影响者 / 使用者 |
| 规模 | 1-10 / 11-50 / 51-200 / 201-1000 / 1000+ |
| 成熟度 | 早期 / 成长 / 成熟 / 衰退 |

### 3.2 细分选择矩阵

```
       高吸引力
         ↑
         │ ★ 核心市场（高增长 + 高匹配）
         │
         │ 标准市场          利基市场
         │（高匹配 / 低增长）（高增长 / 低匹配）
低匹配 ──┼────────────────────────→ 高匹配
         │
         │ 待观察             避免
         │（低增长 / 低匹配）  （高竞争 / 低匹配）
         │
         ↓
       低吸引力
```

**实操**：选 1-2 个核心市场 + 2-3 个标准市场作为目标

### 3.3 细分的市场验证

每个细分市场需验证：
- 客户是否有真实痛点（支付意愿）
- 市场规模是否够大（值得投入）
- 触达路径是否清晰（能获客）
- 自家能力是否匹配（能做出来）

## 4. 增长趋势分析

### 4.1 增长率指标

```
CAGR（Compound Annual Growth Rate）复合年增长率
   CAGR = (End Value / Start Value)^(1/Years) - 1

YoY（Year over Year）同比增长率
   YoY = (今年 - 去年) / 去年

MoM（Month over Month）环比增长率
   MoM = (本月 - 上月) / 上月
```

### 4.2 增长率解读

| 增长率 | 市场状态 | 策略 |
|--------|---------|------|
| > 30% | 高速增长 | 抢占市场，跑马圈地 |
| 10-30% | 稳定增长 | 优化效率，提升渗透 |
| 0-10% | 缓慢增长 | 差异化，寻找新细分 |
| < 0% | 衰退 | 退出或转型 |

### 4.3 增长来源分解

```
增长 = 新客户数 × 客单价 + 老客户数 × 客单价增量 + 老客户数 × 客单价
     = 新增贡献 + 流失负贡献 + 扩展正贡献

每部分量化 → 找最大杠杆点
```

## 5. 地域分析

### 5.1 区域市场特征

| 区域 | 特征 |
|------|------|
| 北美 | 高 ARPU + 竞争激烈 + SaaS 渗透高 |
| 欧洲 | GDPR 严格 + 多语言 + 中 ARPU |
| 中国 | 移动优先 + 微信生态 + 本地化强 |
| 日本 | 高品质要求 + 决策慢 + 高忠诚 |
| 东南亚 | 高速增长 + 价格敏感 + 多语言 |
| 拉美 | 移动优先 + 支付碎片 + 潜力大 |

### 5.2 进入策略

```
直接进入：本地子公司（资源投入大）
合作伙伴：本地代理 / 分销（资源投入小但控制弱）
收购：买现成玩家（最快但风险高）
SaaS 远程：远程团队（成本低但服务难）
```

## 6. 数据来源

### 6.1 一手数据（自有）

```
- 销售数据（已成交客户）
- 用户行为（产品分析）
- 用户调研（NPS / 访谈）
- 客服记录（高频问题）
```

### 6.2 二手数据（外部）

```
- 行业报告：Gartner / IDC / Forrester / 艾瑞 / 36Kr
- 投融资：CB Insights / Crunchbase / IT 桔子
- 招聘：LinkedIn / BOSS 直聘（看团队扩张方向）
- 媒体：行业媒体 / 公众号 / 知乎
- 专利 / 论文：Google Patents / arxiv
```

### 6.3 数据可信度排序

```
一手 > 二手（直接验证） > 二手（间接推断） > 第三方报告 > 道听途说
```

## 8. 反模式

- ❌ TAM 拍脑袋（虚高不可信）
- ❌ 用一种方法测算（应多方法交叉）
- ❌ 不分细分市场（"所有人都是客户" = 没有客户）
- ❌ 数据来源不明（无法验证）
- ❌ 增长率外推无限（线性外推到永远）
- ❌ 只看市场规模不看获客成本
- ❌ 地域分析一刀切（忽视本地差异）
