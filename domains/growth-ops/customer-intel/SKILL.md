# 客户情报 (customer-intel)

## 1. 适用边界

### 1.1 适用场景
- 客户画像构建（基础 + 行为 + 偏好）
- 客户分层（RFM / 价值 / 潜力）
- 个性化营销（按画像定制触达）
- 流失预警（提前识别高流失风险）
- 客户成功管理（高价值客户深度服务）

### 1.2 不适用
- 战略级市场分析（属 `market-intel` skill）
- 用户访谈（属 `user-research` skill）
- 销售线索分析（属 `sales-funnel` skill）

## 2. 客户画像三层模型

### 2.1 基础属性层（静态）

```
Who（身份）：
  - 客户 ID / 名称
  - 公司规模 / 行业 / 地域
  - 决策链角色（决策者/影响者/使用者）

What（业务）：
  - 主营产品 / 服务
  - 营收规模 / 员工数
  - 业务模式（B2B / B2C / GOV）

Contact（联系方式）：
  - 主要联系人（多角色）
  - 沟通偏好（邮件/微信/电话/IM）
  - 时区 / 工作时间
```

### 2.2 行为属性层（动态）

```
Engagement（参与度）：
  - 产品使用频次（DAU/WAU/MAU）
  - 核心功能使用率
  - 最近 7/30/90 天活跃度

Journey（旅程）：
  - 客户旅程阶段（认知/评估/试用/付费/扩展/流失）
  - 关键节点转化率
  - 平均转化时长

Channel（渠道）：
  - 来源渠道（自然/付费/口碑/活动）
  - 触达频率
  - 响应率
```

### 2.3 偏好属性层（推断）

```
Value（价值感知）：
  - 关注的核心功能
  - 痛点优先级
  - ROI 敏感度

Personality（个性）：
  - 决策风格（数据驱动 / 关系驱动 / 直觉驱动）
  - 风险偏好（保守 / 中性 / 激进）
  - 沟通风格（简洁 / 详细 / 视觉 / 文字）

Need（潜在需求）：
  - 已表达的需求
  - 推断的潜在需求
  - 未来 6-12 个月的需求预测
```

## 3. 客户分层模型

### 3.1 RFM 模型（基础）

```
R（Recency）   最近一次消费距今天数
F（Frequency） 消费频次
M（Monetary）  消费金额

分层示例：
  高 R + 高 F + 高 M = 重要价值客户（VIP）
  低 R + 高 F + 高 M = 重要唤回客户
  高 R + 低 F + 高 M = 重要发展客户
  高 R + 高 F + 低 M = 重要保持客户
  低 R + 低 F + 低 M = 一般客户
```

### 3.2 客户价值模型（C-V-P）

```
C（Current Value）  当前价值
   = 年消费金额 × 毛利率

V（潜在 Value）    潜在价值
   = 同类客户平均扩展金额

P（忠诚度）         续约概率
   = 历史续约记录 + NPS + 流失风险
```

### 3.3 客户矩阵

```
       高潜力（V）
         ↑
         │ ★ 重点发展（高 C + 高 V）
         │   投入资源做扩展
         │
         │   重要保持        重要挽留
         │ （高 C + 低 V） （低 C + 高 V）
低 C ────┼────────────────────────→ 高 C
         │
         │   机会探索        待观察
         │ （低 C + 高 V） （低 C + 低 V）
         │
         ↓
       低潜力（V）
```

### 3.4 分层后的差异化策略

| 层级 | 资源投入 | 服务深度 | 触达频率 |
|------|---------|---------|----------|
| 重点发展 | 高 | 专属 CSM + 高管对接 | 周度 |
| 重要保持 | 中 | 共享 CSM | 月度 |
| 重要挽留 | 高（短期） | 应急团队 | 每日 |
| 机会探索 | 中 | 销售主导 | 季度 |
| 待观察 | 低 | 自助为主 | 半年 |

## 4. 客户行为分析

### 4.1 关键行为指标

```
活跃度：DAU/MAU ratio（粘性）
功能使用：核心功能使用率（深度）
内容：内容创建 / 消费（贡献度）
协作：邀请他人 / 团队扩展（传播力）
留存：7/30/90 天留存（粘性）
```

### 4.2 行为模式聚类

```
高频深度用户：DAU + 核心功能 ≥ 5 次/天
高频浅度用户：DAU + 偶尔使用
低频深度用户：低频但每次都做核心操作
低频浅度用户：沉睡用户
流失用户：> 30 天未访问
```

### 4.3 行为驱动因素

```
价值类：付费转化 / 扩展购买
内容类：内容创建 / 分享
社交类：邀请 / 团队协作
学习类：观看教程 / 参加培训
反馈类：提交工单 / 评价
```

## 5. 客户价值评估

### 5.1 LTV（Life Time Value）

```
LTV = 平均客单价 × 年购买频次 × 平均客户生命周期 × 毛利率

例：$100/月 × 12 月/年 × 3 年 × 80% = $2,880
```

### 5.2 LTV / CAC 比率

```
比率 = LTV / CAC

健康：≥ 3:1
优秀：≥ 5:1
危险：< 1:1（赔钱）
```

### 5.3 客户净推荐值（NPS）

```
NPS = 推荐者（9-10 分）占比 - 贬损者（0-6 分）占比

健康：> 30
优秀：> 50
危险：< 0
```

## 6. 流失预警

### 6.1 流失信号

```
使用信号：
  - DAU 持续下降（> 30%）
  - 核心功能停止使用（> 2 周）
  - 团队成员减少（主动退订）

互动信号：
  - 工单减少（开始沉默）
  - 营销邮件打开率降低
  - 客服响应延迟

外部信号：
  - 竞品动作（招聘/产品发布）
  - 公司负面新闻
  - 行业衰退
```

### 6.2 流失评分模型

```
综合流失概率 = f(使用分 + 互动分 + 外部分)

使用分：基于行为指标
  - DAU 下降 > 30%：+30 分
  - 核心功能 0 使用：+25 分
  - 团队减少 > 20%：+25 分
互动分：基于互动指标
  - 工单 0 > 30 天：+20 分
  - 营销邮件不打开：+15 分
  - 客服响应 > 7 天：+15 分
外部分：基于外部信号
  - 竞品签约：+30 分
  - 公司负面：+20 分

总分 > 70：高风险，立即干预
总分 50-70：中风险，季度观察
总分 30-50：低风险，正常维护
总分 < 30：健康客户
```

### 6.3 流失挽回 playbook

```
P0（高风险）：24h 内专属 CSM 联系 + 高管介入
P1（中风险）：3 天内主动回访 + 提供使用培训
P2（低风险）：月度 NPS + 使用建议邮件
```

## 8. 反模式

- ❌ 画像只有基础属性（无行为 + 偏好）
- ❌ 分层一刀切（用 RFM 单一标准）
- ❌ 不区分价值与潜力（误把高价值当低潜力）
- ❌ 流失预警只看使用不看外部
- ❌ 干预策略不分级（所有流失都发同样邮件）
- ❌ 不验证分层效果（分层后业务指标无变化）

## 9. 自我审计清单

- [ ] 画像是否三层（基础 + 行为 + 偏好）
- [ ] 分层是否用 ≥ 2 个模型交叉
- [ ] 行为分析是否有量化指标
- [ ] LTV 测算是否有数据支撑
- [ ] 流失预警是否多信号融合
- [ ] 干预策略是否按流失等级分级
- [ ] 分层后是否有验证机制

如有任何一项未达，**不要**输出 "客户情报完成" 结论。
