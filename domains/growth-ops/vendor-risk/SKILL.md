# 供应商风控 (vendor-risk)

## 1. 适用边界

### 1.1 适用场景
- 新供应商准入审核
- 现有供应商分级管理
- 供应商风险事件应对（违约/合规/舆情）
- 年度供应商复评
- 战略供应商 vs 边缘供应商决策

### 1.2 不适用
- 战略采购决策（属 `procurement-strategy` skill）
- 供应商日常管理（属 `vendor-management` skill）
- 单笔订单风险（属 `transaction-risk` skill）

## 2. 供应商分级（4 档）

### 2.1 分级标准

| 等级 | 标准 | 监控频率 |
|------|------|----------|
| **战略供应商** | 年采购 > 100万 + 关键品类独家 | 季度 + 实时舆情 |
| **核心供应商** | 年采购 20-100万 + 重要品类 | 季度 |
| **普通供应商** | 年采购 5-20万 | 半年度 |
| **边缘供应商** | 年采购 < 5万 | 年度 |

### 2.2 分级的战略意义

```
战略供应商：深度绑定 + 共建能力 + 长期合同
核心供应商：稳定合作 + 多源备份 + 季度评估
普通供应商：标准流程 + 半年评估
边缘供应商：按需采购 + 年度评估 + 必要时替换
```

## 3. 准入审核（9 个维度）

### 3.1 标准审核表

```
1. 资质合规
   ☐ 营业执照（三证合一）
   ☐ 行业资质（如 ISO / CMMI / 行业认证）
   ☐ 出口许可（如涉及）
   ☐ 知识产权合规

2. 财务健康
   ☐ 营收规模（近 3 年）
   ☐ 利润情况
   ☐ 现金流
   ☐ 负债率
   ☐ 主要客户集中度

3. 经营稳定性
   ☐ 成立年限（建议 ≥ 3 年）
   ☐ 核心团队稳定性
   ☐ 关键人员离职率
   ☐ 办公场所稳定性

4. 技术能力
   ☐ 技术栈匹配度
   ☐ 过往项目案例
   ☐ 知识产权（自有专利）
   ☐ 研发投入占比

5. 生产能力（实物采购）
   ☐ 工厂规模 / 设备
   ☐ 产能 / 良率
   ☐ 质量管理体系
   ☐ 环保合规

6. 服务能力
   ☐ SLA 承诺
   ☐ 售后响应时间
   ☐ 培训能力
   ☐ 文档质量

7. 合规风险
   ☐ 反贿赂反腐败承诺
   ☐ 数据保护合规（GDPR / PIPL）
   ☐ 反洗钱
   ☐ 制裁名单核查

8. 法律风险
   ☐ 在诉案件
   ☐ 失信记录
   ☐ 行政处罚
   ☐ 知识产权纠纷

9. 声誉风险
   ☐ 媒体负面报道
   ☐ 客户评价
   ☐ 员工评价（脉脉 / Glassdoor）
   ☐ ESG 评级
```

### 3.2 审核流程

```
Step 1: 资质初审（书面材料）      → 1-3 个工作日
Step 2: 现场考察（关键供应商）    → 0.5-1 个工作日
Step 3: 试单验证（核心供应商）    → 1-3 个月
Step 4: 决策（合格供应商入库）    → 1 个工作日
Step 5: 签订框架协议              → 1 周
```

## 4. 风险评分模型

参考 `risk-scoring` skill 的方法论，供应商风控的典型维度：

```
资质合规（25%）      资质文件完整度 + 行业认证 + 知识产权
财务健康（20%）      营收 + 利润 + 现金流 + 负债率
经营稳定性（15%）    成立年限 + 团队稳定性
技术能力（15%）      技术匹配度 + 项目案例
合规风险（15%）      反贿赂 + 数据保护 + 制裁
法律风险（5%）       在诉案件 + 失信记录
声誉风险（5%）       媒体评价 + 客户评价
```

**风险等级阈值**：
- ≥ 80 分：低风险，正常合作
- 60-79 分：中风险，加强监控
- 40-59 分：中高风险，限制合作
- < 40 分：高风险，拒绝合作

## 5. 过程监控

### 5.1 关键监控点

```
交付：准时率 / 良率 / 退货率
付款：账期遵守率 / 异常付款
合规：证书到期提醒 / 法规更新
舆情：媒体监控 / 客户评价
财务：定期财报（如上市公司）
```

### 5.2 监控频率

| 等级 | 监控频率 | 监控方式 |
|------|----------|----------|
| 战略 | 实时 + 季度复盘 | 专属对接人 + 季度业务评审 |
| 核心 | 月度 + 季度复盘 | 月度数据收集 + 季度业务评审 |
| 普通 | 季度 + 半年度复盘 | 系统化数据收集 |
| 边缘 | 半年度 + 年度复盘 | 年度复评 |

## 6. 风险事件应对

### 6.1 事件分级

| 级别 | 事件类型 | 响应时间 |
|------|---------|----------|
| P0 | 重大合规（腐败/制裁/数据泄露）| 立即 |
| P1 | 严重违约（无法交付/质量事故）| 24h |
| P2 | 中度违约（延期/部分质量问题）| 72h |
| P3 | 轻微违约（小瑕疵）| 1 周 |

### 6.2 应对流程

```
Step 1: 事件确认（24h 内）
Step 2: 影响评估（业务影响 + 财务影响 + 声誉影响）
Step 3: 应急处置（暂停合作 / 启用备份 / 法律行动）
Step 4: 根因调查（5-Why）
Step 5: 整改验证 / 退出决策
Step 6: 复盘 + 更新风控规则
```

## 7. 退出机制

### 7.1 退出触发条件

- 战略供应商变为竞争对手
- 重大合规事件（无法修复）
- 财务破产 / 重组
- 关键人员流失导致能力丧失
- 持续严重违约（3 次 P1 以上）

### 7.2 退出流程

```
Step 1: 决策（高管评审）
Step 2: 业务迁移（启用备份供应商）
Step 3: 合同收尾（尾款 / 责任划分）
Step 4: 知识产权 / 数据交接
Step 5: 历史复盘（教训 + 规则更新）
Step 6: 退出公告（必要时）
```

## 9. 反模式

- ❌ 只看价格不看风险
- ❌ 准入审核流于形式（缺资质照样合作）
- ❌ 不分级（一视同仁）
- ❌ 战略供应商只有 1 家（无备份风险）
- ❌ 监控只看交付不看合规
- ❌ 风险事件隐瞒不报（失去应对窗口）
- ❌ 退出流程无预案（紧急时混乱）
